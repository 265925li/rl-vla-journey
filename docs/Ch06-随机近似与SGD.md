## 零、这一课不教任何算法

先把定位说清楚，否则会觉得这 7 讲「和强化学习没关系」。

第 5 课（蒙特卡洛）里已经写了这么一个更新式：

```
V(s) ← V(s) + α [ G − V(s) ]
```

它凭空出现了。为什么要这么写？为什么 `α` 要随次数变小？为什么不存下所有 `G` 再平均？
**第 5 课没解释，这一课就是来解释的。**

这一课只教三件工具：

| 工具 | 解决什么 | 后面用在哪 |
|---|---|---|
| 迭代均值 | 不存数据怎么求平均 | MC 的增量更新 |
| Robbins-Monro | 只能看到**带噪**的观测，怎么解 `g(w)=0` | TD / Q-Learning 的更新 |
| SGD | 不知道期望，怎么求梯度 | 策略梯度 / Actor-Critic |

一句话：**后面所有算法的更新式，都是这一课那一个式子的变体。**
所以这一课不是「热身」，是**主干**。看不懂它，后面每个更新式都只能背。

## 一、迭代均值：把「平均」写成递推

### 1.1 推导（两行代数）

要算前 `k` 个数的平均：

```
w_k = (1/k)(x_1 + x_2 + ... + x_k)
```

上一轮算过的是 `w_{k-1} = (1/(k-1))(x_1 + ... + x_{k-1})`，所以

```
(k-1)·w_{k-1} = x_1 + ... + x_{k-1}
```

代回去：

```
w_k = [ (k-1)·w_{k-1} + x_k ] / k
    = w_{k-1} − (1/k)·w_{k-1} + (1/k)·x_k
    = w_{k-1} + (1/k)(x_k − w_{k-1})
```

**整个推导只用了一个事实：新平均 = 旧平均加一个修正项。**
修正项等于「新样本与旧平均的差」，乘 `1/k`。

### 1.2 `1/k` 不是超参数

这是最容易含糊过去的一点。`1/k` **不是**「随便选的一个衰减」，
它是**让 `w_k` 恰好等于前 k 个数的算术平均**的那个唯一取值。

推导里 `1/k` 是直接除以 `k` 得来的。换成 `1/(k+5)` 或 `0.9/k`，`w_k` 就不再是算术平均，
而是一个**偏向近期样本**的加权平均 —— 数学上没错，但语义变了。

这一点决定了后面 RL 里 `α` 的性质，见 §4。

### 1.3 实测（实验 A）

`N = 200000` 个 `N(5, 2)` 样本：

| 量 | 值 |
|---|---|
| 全量平均 | 5.000261351105275 |
| 迭代均值 | 5.000261351105315 |
| 差 | **3.997e-14** |
| 内存 | 1562 KB vs **8 B**（20 万倍） |

差 `4e-14` 来自**加法顺序不同**（浮点加法不满足结合律），不是算法不同。
前 5 步与「前 k 个直接平均」的差是 `8.882e-16`，已经在 float64 的 1 ulp 量级。

> **这里有个值得记住的实践判据**：`4e-14` 这个量级的差，
> 出现在任何「本该等价」的实现对比里，都说明**只是求和顺序不同**。
> 如果差到 `1e-10` 以上，就不是顺序问题了。（Day 32 的 float64 地板也是这个道理。）

### 1.4 一句预告

把 `1/k` 换成常数 `α`，得到的就是 RL 里真正用的那个式子：

```
V ← V + α(G − V)
```

代价是：`α` 常数 → **永远在真值附近抖，不会精确收敛**。
抖多少，§4 给出闭式解。

## 二、Robbins-Monro：不知道函数，怎么解 `g(w)=0`

### 2.1 问题设定

要求方程 `g(w) = 0` 的根。麻烦在于：

- `g` 的形式**不知道**（没有解析式）
- 只能「在 `w` 处测一下」，得到一个**带噪**的值 `g̃(w, η) = g(w) + 噪声`

RL 里到处都是这个形状：你想知道「在状态 `s` 采取动作 `a` 有多好」，
但只能跑一次得到一个带随机性的回报。

### 2.2 算法

```
w_{k+1} = w_k − a_k · g̃(w_k, η_k)
```

一步就到位的直觉：`g` 为正说明 `w` 在根右边 → 往左走。`a_k` 控制走多远。

麻烦在噪声：如果 `a_k` 是常数，噪声永远不会被平均掉。

### 2.3 两个条件，各管一件事

```
Σ a_k = ∞         →  能走够远（否则停在半路）
Σ a_k² < ∞        →  噪声被平均掉（否则一直抖）
```

这两条经常被一起背下来，但它们管的是**完全不同**的两件事，实测能直接分开。

### 2.4 实测（实验 B）

根 `w* = 3.0`，噪声 `σ = 1`，跑 10 万步，看最后 1 万步：

| 步长 | `Σa_k` | 末尾均值 | 末尾 std | `|均值−根|` |
|---|---|---|---|---|
| `1/k` | 12.090 | 3.001347 | 0.000356 | 1.347e-03 |
| `α = 0.05` 常数 | 5000.000 | 3.002247 | **0.151050** | 2.247e-03 |
| `1/k²` | **1.645** | **2.912979** | 0.000000 | **8.702e-02** |

三行读法：

1. **`1/k` 两条都满足** → 到得了根（误差 `1.3e-3`），而且抖动在消失（`3.6e-4`）。
2. **`α` 常数**：`Σa_k = ∞` 满足 → 也到了根；但 `Σa_k² = ∞` → **std 永远卡在 0.151**。
3. **`1/k²`**：`Σa_k = π²/6 = 1.645`，**有限的**。总步长就这么点，
   所以只走到 2.913 就停在半路，差 **0.087**。而且它不抖 —— 因为已经彻底不动了。

> `π²/6 = 1.644934` 这个数在这里出现不是巧合：`Σ1/k²` 就是 ζ(2)。
> 实测 `1.645`，对得上。

**所以「收敛」有两种失败方式，长得完全不同**：
一种是停在错的地方（`Σa_k` 有限），一种是对的但一直在抖（`Σa_k²` 发散）。
只看最终误差分不出这两种，必须看**末尾的 std**。

## 三、SGD：把 RM 用在目标函数上

### 3.1 它不是新算法

要最小化

```
J(w) = E[ f(w, ξ) ]
```

梯度

```
∇J(w) = E[ ∇_w f(w, ξ) ]
```

**期望算不出来**（分布未知）。于是用一次采样代替：

```
w_{k+1} = w_k − a_k · ∇_w f(w_k, ξ_k)
```

把它和 §2.2 摆在一起看：**这就是 RM，只不过 `g` 取成了 `∇J`。**

```
RM：  g(w) = 0          →  w ← w − a·g̃
SGD： ∇J(w) = 0         →  w ← w − a·∇f
```

**SGD = RM 的特例。** 这不是「类比」，是同一个定理的两个用法。

### 3.2 三种批大小，成本一样，更新次数差 B 倍

一个 epoch = 把 `n` 个样本各过一遍，此时：

| 方法 | 一个 epoch 的更新次数 | 每次更新的成本 |
|---|---|---|
| BGD（全批） | 1 | `n` |
| MBGD（批 = B） | `n/B` | `B` |
| SGD（批 = 1） | `n` | `1` |

**总样本消耗完全相同**，差别全在「这 `n` 个样本被切成几次用」。

### 3.3 实测（实验 D）

`J(w) = ½E[(w−x)²]`，`x ~ N(5, 2)`，`n = 10000`，`lr = 0.1`，20 个 epoch。
三者样本预算都是 20 万。表中是**每个 epoch 内 `|w−w*|` 的均值**：

| 方法 | 更新次数 | 第 1 轮均值 | 第 5 轮 | 末轮均值 | 末轮抖动 |
|---|---|---|---|---|---|
| BGD | **20** | 4.5114 | 2.9599 | 0.6094 | 0.0000 |
| MBGD (B=100) | 2000 | 0.4647 | 0.0318 | **0.0325** | 0.0231 |
| SGD | **200000** | 0.3593 | 0.3671 | 0.3564 | 0.2728 |

三个结论，一个比一个反直觉：

1. **BGD 每次更新都非常准，但一轮只有 1 次。** 20 次更新后误差还有 0.61。
2. **SGD 第一轮就到 0.3593，比 BGD 跑满 20 轮还好。** 这就是它流行的原因。
3. **但 SGD 之后再也没进步**：0.3593 → 0.3564，20 万次更新白费。
   而 MBGD 用 2000 次更新做到 0.0325。

> ⚠️ **这一条是最容易读错的地方**：不能说「MBGD 比 SGD 好」。
> SGD 卡住的不是速度，是 §4 那条**抖动地板**。地板高度由 `α` 和噪声决定，
> 跟跑了多少步无关。所以「多跑一会儿」救不了它，只有**降 `α`** 或**加大 B** 能救。

## 四、常数步长 = 永远在抖（本课最重要的一节）

### 4.1 手推

设根为 `w*`，误差 `e_k = w_k − w*`。在根附近把 `g` 线性化（`g'(w*) ≈ 1`，为了算式干净），
常数步长 `α`：

```
w_{k+1} = w_k − α[(w_k − w*) + ξ_k]
e_{k+1} = e_k − α e_k − α ξ_k = (1−α)e_k − α ξ_k
```

这是一个 AR(1) 过程。取稳态（`Var(e_{k+1}) = Var(e_k) = s²`，且 `e` 与 `ξ` 独立）：

```
s² = (1−α)² s² + α² σ²
s² [1 − (1−α)²] = α² σ²
```

而 `1 − (1−α)² = 2α − α²`，所以

```
s² = α²σ² / (2α − α²) = ασ² / (2−α)
```

```
        ┌──────────────────┐
        │  s = sqrt( ασ² / (2−α) )  │
        └──────────────────┘
```

`α` 很小时约等于 `σ·sqrt(α/2)` —— **抖动 ∝ √α，不是 ∝ α**。

### 4.2 实测对拍（实验 C）

`σ = 1`，跑 20 万步，取最后 5 万步的 std：

| `α` | 实测 std | 理论 std | 相对误差 | `std/√α` |
|---|---|---|---|---|
| 0.01 | 0.072369 | 0.070888 | 2.09e-02 | 0.7237 |
| 0.02 | 0.101197 | 0.100504 | 6.89e-03 | 0.7156 |
| 0.05 | 0.160335 | 0.160128 | 1.29e-03 | 0.7170 |
| 0.10 | 0.229406 | 0.229416 | **4.38e-05** | 0.7254 |
| 0.20 | 0.332699 | 0.333333 | 1.90e-03 | 0.7439 |

公式对得很干净。最后一列 `std/√α` 在 0.71–0.74 之间基本恒定，
理论值 `σ/√2 = 0.7071` —— **抖动 ∝ √α 被证实**。

> **为什么 `α = 0.01` 的相对误差 2% 最大？**
> 不是公式错了。`α` 越小，自相关时间 `≈ 1/α` 越长（`α=0.01` 时约 100 步），
> 5 万步尾巴里**独立样本只有约 500 个**，std 的相对标准误就有 `1/√(2×500) ≈ 3.2%`。
> 2% 完全在噪声内。**容差必须匹配被测精度** —— 这条已经踩过一次，这里是它的正面案例。

### 4.3 三条推论

**推论 1：学习率必须衰减。**
只要 `α` 是常数，精度就有地板，地板是 `sqrt(ασ²/(2−α))`。
想让损失降到 0，必须让 `α → 0`（这就是 `1/k` 那条路）。

**推论 2：地板 ∝ √α，降 `α` 的收益是平方级的。**
想把精度提高 10 倍，`α` 要降 **100 倍**。这也解释了为什么「调小学习率」经常感觉几乎没效果 ——
你降了 2 倍，精度只好了 1.4 倍。

**推论 3：加大 batch 等于降噪。**
批均值噪声是 `σ/√B`，套进同一个公式：

```
s_B = sqrt( α σ² / (B(2−α)) )  =  s_1 / √B
```

`B = 100` 时地板低 **10 倍**。

### 4.4 用同一个公式解释实验 D

`α = 0.1`，`σ = 2`：

| 方法 | 理论地板 `s` | `×0.6028` 预测的 `std(|e|)` | 实测末轮抖动 |
|---|---|---|---|---|
| SGD | `sqrt(0.1×4/1.9) = 0.4588` | 0.2766 | **0.2728** |
| MBGD | `sqrt(0.1×4/(100×1.9)) = 0.0459` | 0.0277 | **0.0231** |

（`0.6028 = sqrt(1 − 2/π)`：高斯变量取绝对值后，标准差缩这个比例。）

**实验 C 的公式直接预测了实验 D 的现象，误差 1.4%。** 两个独立实验互相验证，
这是这一章最硬的一块。

## 五、两个不变性（实验 E）

### 5.1 加常数：轨迹逐位相同

对 `J(w)` 和 `J(w) + 100` 各跑一遍 SGD，同样的数据、同样的顺序：

```
轨迹最大差 = 0.000e+00    逐位相同 = True
```

原因一句话：**常数项的导数是 0，它根本没进梯度。**
代码里那一行 `g = scale * (w - xi)` 里没有 `shift`，这不是省略，这就是证明。

### 5.2 乘常数：等价于调学习率

`J → 3J` 与 `lr × 3` 的轨迹，最大差 `1.776e-15`（float64 尾数级别，本质是同一个轨迹）：

```
3·∇J(w), lr=α     ≡     ∇J(w), lr=3α
```

**所以「目标函数缩放」和「学习率」是同一个自由度**，调整其中一个必须固定另一个，
否则实验不可比。这也是为什么 RL 里奖励缩放（reward scaling）会直接改变有效学习率。

### 5.3 呼应前面

Day 29 证明过 `V` 的平移不变性（`V + c` 不改变贪心选择），Day 31 证明过 `max` 提不出 `Σ`。
今天这两条是同一族性质在优化层面的版本：**先问「这个变换改变了什么」，再谈它有没有用。**

## 六、这一课没给你什么

按惯例，把缺口明写出来 —— 缺口本身是下一章的动机。

| 缺口 | 后果 | 在哪补 |
|---|---|---|
| **只给了凸情形的收敛率** `O(1/k)`，没证 | 知道结论不知道适用边界 | 需要时查原著 |
| **完全没讲「目标在动」的情形** | RL 的 `J` 一直在变（`V` 用自己更新自己） | **第 7 课 TD**，这是 TD 有偏的根 |
| 没讲 momentum / Adam | 但这是工程细节，不是原理 | 需要时补 |
| 收敛条件是**充分**的，不是必要的 | 满足 `Σa_k=∞, Σa_k²<∞` 一定收敛；不满足不一定不收敛 | 实测 B 里 `α` 常数就是反例：不满足第二条，但仍然到了根附近 |

**最后一条是本课最值得带到 RL 里去的一句话**：

> RM 的定理假设 `g(w)` 是**固定的**。
> 而 TD 的更新是 `V(s) ← V(s) + α[r + γV(s') − V(s)]`，
> 右边含 `V` 自己 —— **`g` 在更新过程中一直在变**。
> 定理的前提在 RL 里根本不成立。这就是 TD 有偏、以及 DQN 需要目标网络的源头。
> 第 7 课会正面撞上它。
