## ⚠️ 怎么跑 Python（每次都要用，先看这段）

**你这台机器上，`conda activate pytorch` 在 PowerShell 里是无效的**（实测报错"系统找不到指定的路径"）——因为 conda 4.10.3 从未对 PowerShell 做过初始化。所以**不要**照搬别的教程里"先 activate 再 python"的写法。

### 方式 A：直接指定解释器的完整路径 ✅ 最推荐

不需要激活，永远有效：

```powershell
& "E:\anaconda\envs\pytorch\python.exe" 完整路径\脚本名.py
```

也可以先切目录再用相对路径（注意路径里有空格，"work Buddy" 必须加引号）：

```powershell
cd "E:\work Buddy\强化学习"
& "E:\anaconda\envs\pytorch\python.exe" 00-setup\check_env.py
```

> `&` 是 PowerShell 的调用运算符，因为路径带引号，少了它会报错。

### 方式 B：用 Anaconda Prompt

开始菜单搜 **Anaconda Prompt** 打开，那里 `conda activate pytorch` 是正常的：

```powershell
conda activate pytorch
python 00-setup/check_env.py
```

### 方式 C：让 PowerShell 里能用 `conda activate`（可选，一劳永逸）

只改你个人的 PowerShell 配置，不动系统：

```powershell
& "E:\anaconda\shell\condabin\conda-hook.ps1"   # 只在当前窗口生效
conda activate pytorch
```

想永久生效（会在 `C:\Users\你\Documents\WindowsPowerShell\` 下新建 profile）：

```powershell
& "E:\anaconda\Scripts\conda.exe" init powershell
# 然后关掉终端重新打开
```

### 绝对不要这样做 ❌

```powershell
python 00-setup/check_env.py       # ← 会用到野生的 Python 3.12
pip install 任意包                  # ← 会装进那个没有 torch 的环境
```

PATH 里的 `python` 指向 `C:\Users\...\Programs\Python\Python312`，**那里面没有 torch**，会直接 `ModuleNotFoundError`。这套计划里的"环境铁律"指的就是这件事：**永远确保你用的一定是 `E:\anaconda\envs\pytorch\python.exe`**。

### 怎么确认自己用对了

任何脚本跑起来，第一件事是看它打印的 **解释器路径**：

```
解释器 : E:\anaconda\envs\pytorch\python.exe   ← 对
解释器 : C:\Users\...\Python312\python.exe     ← 错，停
```

`00-setup/check_env.py` 会自动打印这一行，所以它同时也是"我在不在正确环境里"的检测器。

> | 7 | 真模型 100 步 | 参数最大差 `2.98e-08` |
>
> **今天抓到的三个静默坑**（都不在正常路径上报错）
> - **存中间量而非输入** → `gradcheck` 过，但 `gradgradcheck` 报「analytical gradient is all zeros」。因为 `p` 在 `no_grad` 里算，身上没有图。改成存 `logits`、backward 里重算 `softmax` 才通。
> - **`ctx.p = p` 而非 `save_for_backward`** → 原地改缓存**不报错**，第 1 次 backward 完全正确（差 `0.00e+00`），第 2 次差 `1.25e-01`。而 `save_for_backward` 版本会被版本检查当场拦下（`RuntimeError: ... modified by an inplace operation`）。**同一个 bug，两种写法，一个报错一个静默。**
> - **漏乘 `grad_out`** → 单测 `loss.backward()` 时 `grad_out=1.0`，完全看不出；一旦上游 `loss*3` 梯度就少乘 3。
>
> **真实验：同 seed 跑 `--loss ce` vs `--loss myce`**
> | | 官方 ce | 手写 myce | 差 |
> |---|---|---|---|
> | ep1 train_loss | 0.299729 | 0.299729 | **0** |
> | ep1 val_loss | 0.148882 | 0.148860 | +2.2e-05 |
> | ep2 val_loss | 0.110548 | 0.114138 | **−3.6e-03** |
> | test acc | 0.9701 | 0.9698 | 3 条样本 |
>
> - 第一轮前 6 位小数全同 → **单步一致**；第二轮分叉 → **浮点误差被 SGD 放大 36 万倍**
> - test 差 0.03 pt < 标准误 0.17 pt（10000 条，p≈0.97）→ **完全在噪声内**
> - 正确表述不是「完全一样」，而是「**单步数值一致，多步因误差累积而分叉，最终差异远小于统计噪声**」
> - 这解释了 Day 15 那条「0.9792 和 0.9793 之间没有区别」的物理原因
>
> **双层 softmax 实测**（用 Day 13 训好的模型）：正确 `loss=0.0307`，末尾多加一层 softmax 变 `1.4837`（**48 倍**），理论下界 `-ln(e/(e+9)) = 1.4612`。**不报错，loss 只是卡住不动。**
>
> **提交**：`6eaaa76`

**目标**：P0 的核心任务之一——把 Day 9 的推导落成可对拍的代码。
