## 四、磁盘长期建议

C 盘 120 GB 对开发机偏小。腾讯系（微信/QQ）+ 金山 + 百度 + JetBrains 合计已占约 20 GB 在 C 盘用户目录下。

最有效的做法不是反复清理，而是**把这些应用的存储位置一次性迁到 D 盘或 E 盘**：
1. 微信：设置 → 文件管理 → 更改存储位置
2. QQ：设置 → 基本设置 → 文件管理
3. JetBrains：IDE 内 `Invalidate Caches / Restart`，并在 IDE 配置里改系统缓存目录
4. pip：`pip config set global.cache-dir "E:\pip-cache"`
5. conda：在 `.condarc` 里设置 `pkgs_dirs`（E 盘已有 `E:\anaconda\pkgs`，无需改）
