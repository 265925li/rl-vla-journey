## 一、先看清「压缩」这两个字到底在说什么

### 1.1 定义

设 `X` 是一个带距离的空间（这里是 `ℝⁿ`，距离用 `‖·‖∞`）。映射 `f: X → X` 是
**γ-压缩**（`0 ≤ γ < 1`），如果对任意 `x, y ∈ X`：

```
‖f(x) − f(y)‖  ≤  γ ‖x − y‖
```

**它只说一件事：你做一次 `f`，任意两点之间的距离至少缩到 γ 倍。**

注意这不是「`f` 是连续的」那种温和条件。它是**一致的、有固定比例的收缩**：

| | 连续 | 压缩 |
|---|---|---|
| 保距离吗 | 不放大（局部） | **按固定比例缩小**（全局） |
| 比例 | 没有 | **γ，且 γ < 1** |
| 迭代 `f^k` 会怎样 | 可能到处乱跑 | **必然挤到一个点** |

### 1.2 为什么这一个不等式能杀掉所有歧义

你可能觉得「一个不等式而已」。它其实同时干掉了三件事，而且每件都只要一两行。

**① 最多一个不动点。**

假设 `x` 和 `y` 都是不动点（`f(x)=x`，`f(y)=y`）：

```
‖x − y‖ = ‖f(x) − f(y)‖ ≤ γ‖x − y‖
⟹ (1 − γ)‖x − y‖ ≤ 0
⟹ ‖x − y‖ = 0        （因为 1 − γ > 0）
⟹ x = y
```

**一行。** 这是整个 RL 里「`V*` 唯一」的最终来源。Day 31 我说「`V*` 唯一但理由和线性方程不同」，
理由就是这个 —— 不是可逆性，是压缩性。

**② 迭代必然收敛到它，而且是几何速度。**

如果 `x*` 是不动点，`x_{k+1} = f(x_k)`：

```
‖x_{k+1} − x*‖ = ‖f(x_k) − f(x*)‖ ≤ γ‖x_k − x*‖
⟹ ‖x_k − x*‖ ≤ γ^k ‖x_0 − x*‖
```

**又一行。** 右边是 `γ^k`，不是「慢慢变小」。`γ=0.9` 时 100 轮降 `0.9^100 ≈ 2.66e-5` 倍。

**③ 至少有一个不动点 —— 这一条要额外的东西。**

①②都假设了不动点存在。存在性不是不等式给的，它需要空间的**完备性**（§2.3）。
这一步很多人跳过，跳过之后「Banach 定理」就变成了一条咒语。

### 1.3 一条纪律：压缩定理有三个前提

```
① X 非空
② X 完备（柯西列的极限还在 X 里）
③ γ < 1（严格小于）
```

**三条缺一条，结论就不成立。** 后面 §6 会把 ③ 的两头都试一遍（`γ=1` 和 `P` 不是随机矩阵），
§2.3 会给出 ② 的反例。这是今天的固定套路：**凡是用一个定理，先问它的前提在我这儿成立吗。**

## 二、Banach 不动点定理

### 2.1 陈述

> 设 `(X, d)` 是**非空完备**度量空间，`f: X → X` 是 **γ-压缩**（`γ < 1`）。
> 则：`f` 存在**唯一**不动点 `x*`；且从**任意** `x_0` 出发，`x_{k+1} = f(x_k)` 收敛到 `x*`，
> 速度是 `‖x_k − x*‖ ≤ γ^k ‖x_0 − x*‖`。

一句话：**压缩 ⟹ 存在、唯一、随便从哪出发都收敛，速度是 γ^k。**

### 2.2 三个结论的来路

| 结论 | 靠什么 | 代价 |
|---|---|---|
| 唯一 | 那个不等式本身 | 一行（§1.2 ①） |
| 收敛速度 | 那个不等式反复用 | 一行（§1.2 ②） |
| **存在** | **柯西列 + 完备性** | 半页，但省不掉 |

存在性的证明骨架（不展开，但要看清依赖什么）：

```
任取 x_0，令 x_{k+1} = f(x_k)
⟹ ‖x_{k+1} − x_k‖ ≤ γ^k ‖x_1 − x_0‖              ← 压缩性
⟹ 对 m > n：‖x_m − x_n‖ ≤ Σ_{j=n}^{m−1} γ^j ‖x_1 − x_0‖ ≤ γ^n/(1−γ) ‖x_1 − x_0‖
⟹ {x_n} 是柯西列
⟹ 由完备性，存在 x* 使 x_n → x*
⟹ 由压缩性（f 连续），f(x*) = x*                 ← 极限和 f 可交换
```

**关键就在第四步。** 前三步只用到压缩，第四步用到完备 —— **没有完备性，柯西列可能没有极限。**

### 2.3 完备性为什么不能省（一个精确的反例）

取 `X = ℚ`（有理数，距离用普通绝对值），`f(x) = (x + 1/x)/2`。

- **`f` 把 ℚ 映到 ℚ**：有理数加、除还是有理数。✓
- **`f` 是压缩**：`f'(x) = (1 − 1/x²)/2`，在 `[3/2, 2]` 上 `|f'| ≤ 5/18 < 1/2`。
  所以 `f` 在这段上是 `1/2`-压缩。✓
- **`f` 唯一的不动点是 `x = 1/x`，即 `x = √2`。而 `√2 ∉ ℚ`。** ✗

于是：`ℚ` 上的这个 `f` 满足①②，**却没有不动点**。从 `x_0 = 3/2` 出发：

```
1.5 → 1.4166666... → 1.4142156... → 1.4142135...
```

每一步都是有理数，序列是柯西列，但极限 `√2` 不在空间里。**定理的结论凭空消失了。**

```
⚠️ 所以 Banach 定理的真正内容是：
   「完备空间上的压缩映射必有不动点」。
   丢掉「完备」两个字，它就只是一句话，不是定理。
```

**RL 里为什么不用担心**：`X = ℝⁿ` 是完备的（这个事实本身要用实数完备性来证，
但那是一年级分析的事，这里当成已知）。所以我们只需要盯住 `γ < 1` 这一条。

## 三、证明 `T*` 是 γ-压缩

现在把 §1 的不等式套到贝尔曼算子上：

```
(T*V)(s) = max_a Σ_s' P(s'|s,a) [ R(s,a,s') + γ V(s') ]
```

要证：`‖T*V − T*U‖∞ ≤ γ ‖V − U‖∞`。

**这条路只需要两个引理，都不用碰 `max` 的展开。**

### 3.1 引理 1：单调性

> 若 `V ≤ U`（逐分量），则 `T*V ≤ T*U`（逐分量）。

证明：对任意 `s, a`，

```
Σ_s' P(s'|s,a)[R + γV(s')]  ≤  Σ_s' P(s'|s,a)[R + γU(s')]
```

因为每一项里 `γV(s') ≤ γU(s')`，且权重 `P(s'|s,a) ≥ 0`。**逐项比较后加权求和，不等式保持。**

再对 `a` 取 `max`：逐项更大的东西，最大值也更大。∎

**依赖的前提：`P ≥ 0` 和 `γ ≥ 0`。** 没有别的。

> ⚠️ 如果转移里出现负元素（现实中不该有，但代码 bug 会有），这个引理当场失效，
> 后面整条链断掉。这就是「一个不该出现的数能摧毁一条定理」的例子。

### 3.2 引理 2：常数平移

> 对任意常数 `c`：`T*(V + c·1) = T*V + γc·1`（`1` 是全 1 向量）。

证明：对任意 `s, a`，

```
Σ_s' P(s'|s,a)[R + γ(V(s') + c)]
  = Σ_s' P(s'|s,a)[R + γV(s')] + γc Σ_s' P(s'|s,a)
  = Σ_s' P(s'|s,a)[R + γV(s')] + γc          ← 这里用了 Σ_s' P = 1
```

每行都多出同一个 `γc`，与 `a` 无关。对 `a` 取 `max` 之后再整块加上 `γc` 不影响谁最大：

```
max_a [ q(s,a) + γc ] = max_a q(s,a) + γc
```

∎

**依赖的前提：`Σ_s' P(s'|s,a) = 1`，也就是 `P` 是随机矩阵。** 只此一条。

### 3.3 主定理：三行

设 `c = ‖V − U‖∞`。

```
第 1 行   由 ∞-范数的定义：  V − U ≤ c·1，即 V ≤ U + c·1

第 2 行   两边作用 T*，用引理 1（单调）再用引理 2（平移）：
          T*V ≤ T*(U + c·1) = T*U + γc·1

第 3 行   交换 V 和 U 再来一遍：  T*U ≤ T*V + γc·1

合起来：  |T*V − T*U| ≤ γc·1   逐分量
取 ∞-范数：  ‖T*V − T*U‖∞ ≤ γc = γ‖V − U‖∞     ∎
```

**证完了。** 没有展开 `max`，没有讨论哪个动作最优，没有遇到任何下标纠缠。

### 3.4 `‖P‖∞ = 1` 到底用在哪

我在上一条消息里说「`‖P‖∞ = 1` 被用掉两次，一正一反」。**那句话指的是课程 p11 的那条路，今天主推的这条路更省。**

两条路的对照：

| | 课程 p11（argmax 展开） | 今天（单调 + 平移） |
|---|---|---|
| 第一步 | 记 `π_V = argmax`、`π_U = argmax`，各写一遍 | 一个 `c`，一个不等式 |
| 用到的界 | `P^π x ≤ ‖x‖∞ · 1`，**正反方向各一次** | 引理 1 用 `P ≥ 0`，引理 2 用 `P·1 = 1` |
| 需要的准备 | 矩阵 ∞-范数的性质 | 两个两行引理 |
| 长度 | 约十行 | 三行 |

两条路要求的是**同一件事**：`P ≥ 0` 且 `P·1 = 1`。后者等价于说随机矩阵的 ∞-范数是 1：

```
‖P‖∞ = max_i Σ_j |P_ij| = max_i 1 = 1        （因为非负且行和为 1）
```

**而 `P ≥ 0` 和 `P·1 = 1` 合起来，正好就是 `‖P^π‖∞ = 1`。**

所以更准确的说法是：

```
单调性  ←  P ≥ 0
平移性  ←  P·1 = 1
合起来  ←  ‖P^π‖∞ = 1
```

## 四、补上 Day 31 的缺口

现在手里有：`T*` 是 γ-压缩 ⟹ 唯一不动点 `V̄`，且任意初值迭代收敛到它。
要证：`V* = V̄`。

### 4.1 (a) `V* ≤ V̄`

Day 31 证过 `V* ≤ T*V*`。由单调性（引理 1），对 `k` 归纳：

```
V* ≤ T*V* ≤ T*²V* ≤ T*³V* ≤ ...
```

所以序列 `{T*^k V*}` **单调不减**。另一方面 Banach 定理说从任意初值迭代都收敛到 `V̄`，
所以这个序列的极限就是 `V̄`。单调不减且极限为 `V̄` ⟹ 首项 `≤ V̄`：

```
V* ≤ V̄
```

### 4.2 (b) `V̄ ≤ V*`

`V̄ = T*V̄` 是不动点。在 `V̄` 处取贪心策略：

```
π̄(s) = argmax_a Σ_s' P(s'|s,a)[R(s,a,s') + γV̄(s')]
```

那么 `T*V̄ = T^{π̄}V̄`（取 max 的那个动作就来自 `π̄`）。于是

```
V̄ = T^{π̄} V̄
```

也就是说 `V̄` 是 `T^{π̄}` 的不动点。而**策略定了之后 `T^{π̄}` 的唯一不动点就是 `V^{π̄}`**
（Day 30：`(I − γP^{π̄})` 可逆，解唯一），所以

```
V̄ = V^{π̄}
```

再由 Day 31 的定义 `V* = max_π V^π`（逐分量最大），有 `V^{π̄} ≤ V*`，于是

```
V̄ ≤ V*
```

### 4.3 结论

```
V* = V̄        （因此 V* 是 T* 唯一的不动点）
π̄ 就是最优策略  （在 V* 处贪心）
```

**这就是为什么「只要 `Q*` 准，贪心就够」** —— Day 31 那句话当时是观察，
现在有证明了：贪心策略是那个让贝尔曼最优方程成立的动作集合，
所以它一定最优。

而且顺带说明**最优策略一定存在**（`π̄` 就是），**而且是确定性贪心的**。
Day 31 只说了「`π*` 不一定唯一」，没说「一定存在」。

### 4.4 实验 C：存在、唯一、收敛，一次全拿到

真值不走迭代 —— 先迭代拿到贪心策略，再解 `(I − γP^π)V = R^π` 精确解，
最后**把解代回 `T*` 验证残差**（残差不为零说明策略不是最优的）：


|---|---|---|---|

| 随机 1 | 283 | 8.455e-13 | 1.565e+02 |

## 五、那个 `1/(1−γ)` 到底从哪来

Day 31 §4.2 留了一句「停止判据乐观 `1/(1−γ)` 倍」。今天给出完整推导，并且**收紧一档**。

### 5.1 两条不等式

记 `d_k = ‖V_k − V_{k−1}‖∞`（相邻差），`e_k = ‖V* − V_k‖∞`（真误差）。

**a priori（先验界）**：从 §1.2 ② 直接来

```
e_k ≤ γ^k · e_0
```

**a posteriori（后验界）**：手上有 `d_k`，要估 `e_k`

```
e_k = ‖T*V* − T*V_{k−1}‖  ≤ γ‖V* − V_{k−1}‖ = γ·e_{k−1}
e_{k−1} = ‖V* − V_{k−1}‖ ≤ ‖V* − V_k‖ + ‖V_k − V_{k−1}‖ = e_k + d_k
代入第一式：  e_k ≤ γ(e_k + d_k)
⟹  e_k (1 − γ) ≤ γ d_k
⟹  e_k ≤ γ·d_k / (1 − γ)
```

**两行，用到的东西只有三角不等式和压缩性。**

### 5.2 为什么是 `γ/(1−γ)` 而不是 `1/(1−γ)`

书上常见的写法是 `e_k ≤ d_{k+1}/(1−γ)`，用的是**下一轮**的相邻差：

```
e_k = ‖V* − V_k‖ ≤ e_{k+1} + d_{k+1} ≤ γ e_k + d_{k+1}  ⟹  e_k ≤ d_{k+1}/(1−γ)
```

也对。但 `d_{k+1} ≤ γ d_k`，所以那个版本比 `γ d_k/(1−γ)` **松**。

**用同一轮的 `d_k`，常数就该是 `γ/(1−γ)`。** `γ = 0.9` 时是 **9**，不是 10。

|---|---|---|---|

| 2 | 2.877e+00 | 2.292e+01 | 7.9668 |
| 3 | 2.306e+00 | 2.061e+01 | 8.9404 |
| 10 | 1.095e+00 | 9.858e+00 | **9.0000** |
| 40 | 4.643e-02 | 4.179e-01 | **9.0000** |
| 160 | 1.499e-07 | 1.349e-06 | **9.0000** |
| 280 | 4.903e-13 | 4.356e-12 | 8.8841 |
| 320 | 7.105e-15 | 6.395e-14 | **9.0000** |

第 10 轮之后几乎钉死在 9.0000 上。**这个 9 不是巧合，是 `γ/(1−γ)` 的实测值。**

### 5.3 操作结论：判据怎么写

```
❌  if ‖V_{k+1} − V_k‖ < ε:  break          # 只保证 e_k < 9ε（γ=0.9）
✅  if ‖V_{k+1} − V_k‖ / (1 − γ) < ε:  break   # 保守，够用
✅  if γ‖V_{k+1} − V_k‖ / (1 − γ) < ε:  break  # 紧，就是上面那个界
```

实验 D 抓到的那一下：**停在第 280 轮时 `d_k = 4.903e-13` 已经小于 `1e-12`，
但 `e_k = 4.356e-12`，是容差的 4.4 倍。**

Day 31 在另一个环境上量到 8.1 倍 —— 落在 `γ/(1−γ) = 9` 之内。**两天的数不冲突，
今天只是把「`1/(1−γ)`」这个习惯说法收紧成了 `γ/(1−γ)`。**

### 5.4 轮数公式，以及 float64 给出的一条硬地板

**要多少轮**：从 `V_0 = 0` 出发，`e_0 = ‖V*‖ ≤ R_max/(1−γ)`（Day 29 的界），于是

```
e_k ≤ γ^k · e_0 < ε
⟹  k ≥ log( ε(1−γ)/R_max ) / log γ
```

实际算的时候用可测的 `‖V₁ − V₀‖` 代替 `R_max` 更紧（`‖V₁−V₀‖ ≤ R_max`），
脚本里用的就是它：`k ≥ log(ε(1−γ)/‖V₁−V₀‖)/log γ`。

实验 E 对账（`ε = 1e-12`，`‖V₁−V₀‖ = 3.4887`）：

| γ | 公式上界 | 按真误差停 | 按相邻差停 | **float64 地板** |
|---|---|---|---|---|
| 0.5 | 42.7 | 43 | 43 | 8.88e-16 |
| 0.9 | 296.0 | 294 | 274 | 2.49e-14 |
| 0.99 | 3331.8 | **不可达** | 2857 | **3.98e-12** |
| 0.999 | 35770.4 | **不可达** | 28577 | **5.61e-10** |

**前两列**：公式是上界，实测贴着它（差 0~1 轮）。推导没错。

**第三、四列**：「按相邻差」永远比「按真误差」早停。省下的那些轮，代价就是 §5.2 的 9 倍。

**第五列是我原来没算到的，也是今天最意外的一条：**

```
γ = 0.99   →  float64 最好只能到 3.98e-12
γ = 0.999  →  最好只能到 5.61e-10
```

而那两行的目标是 `1e-12`。**所以「不可达」不是慢，是不可能。**

原因不是代码写错，是**舍入误差本身也被 `1/(1−γ)` 放大了**：

```
每步浮点运算注入约 eps·|V| 的噪声
   ↓ 被压缩映射累积
噪声稳态 ≈ eps·|V| / (1−γ)
   ↓ 而 |V| ~ R_max/(1−γ)
地板 ≈ R_max · eps / (1−γ)²
```

验算：`γ=0.999` 时 `|V| ≈ 2826`，`eps·|V| ≈ 6e-13`，除以 `0.001` 得 `6e-10`，
与实测 `5.61e-10` 同量级（差不到 2 倍，剩下的因子来自 `max` 的取法和有效位数）。

```
⚠️ 所以「γ=0.999 时值迭代收敛到 1e-12」这句话做不到，不是慢，是不可能。
   看到有人这么报，要么他用了更高精度，要么他报的是相邻差。
```

这条在实践里的意思：**γ 大时不要执着于迭代法的精度，去解线性方程组**
（`γ=0.999` 时 `I − γP` 的条件数量级是 `1/(1−γ) ≈ 1000`，解方程仍能把残差压到 `1e-12` 以内）。
**迭代法的优势是「不需要显式知道 P」**（W6 起就是这个场景），
**不是精度。**

## 六、前提不在，结论不在

### 6.1 `γ ≥ 1`：压缩因子的精确值就是 γ

实验 F（`γ=0.9` 一行与实验 A 独立抽样，所以随机最大比略不同）：

| γ | 随机对最大比 | **最坏情况** | 小于 1？ | 400 轮后 `\|V\|` |
|---|---|---|---|---|
| 0.9 | 0.854370 | **0.900000** | 是 | 2.928e+01 |
| 1.0 | 0.963822 | **1.000000** | **否** | 1.132e+03 |
| 1.5 | 1.438699 | **1.500000** | **否** | 1.545e+71 |

**最坏情况一列恰好等于 γ。** 所以 `γ < 1` 不是「保守的充分条件」，
它是**精确的边界** —— 差这一点（`γ=1`，因子正好 1）定理就整条不成立。

`γ = 1` 那一行更要注意：值的大小是

```
100 轮 283.8  →  200 轮 566.5  →  400 轮 1131.9
```

**每 100 轮涨同样的量，线性增长。** 它不报错、不 nan、数值还有意义，
但**永远停不下来**。这是最阴的一种失败 —— 你会以为再多跑几轮就好了。

### 6.2 `P` 不是随机矩阵：压缩因子变成 `γ(1+δ)`

§3.5 那张 δ 表已经说了。这里只把逻辑串起来：

```
引理 2  ⟸  Σ_s' P(s'|s,a) = 1
⟹  行和 = 1+δ 时平移量变成 γc(1+δ)
⟹  压缩因子 γ(1+δ)
⟹  δ > 1/γ − 1 时因子 > 1，不再是压缩
```

`γ = 0.9` 时阈值是 `δ > 0.111`。**行和偏 12% 就越界了。**

### 6.3 完备性：§2.3 的 √2 反例

`ℚ` 上 `f(x) = (x + 1/x)/2` 是压缩，没有不动点。这是唯一一条**不会在代码里犯**的前提
（`ℝⁿ` 一定完备），但它是「为什么需要四条前提」的答案。

## 九、今天带走的五句话

1. **压缩 = 一个不等式：`‖f(x)−f(y)‖ ≤ γ‖x−y‖`。** 它一行给出唯一性、一行给出收敛速度；
   存在性要完备性（`ℚ` 上求 `√2` 的反例）。
2. **`T*` 是 γ-压缩，证明只要三行**：`V − U ≤ c·1` → 单调 → 平移 → 交换再来一遍。
   **不需要展开 `max`。**
3. **两条前提各用一次**：`P ≥ 0` 给单调性，`P·1 = 1` 给常数平移。
   合起来就是 `‖P^π‖∞ = 1`。**`P` 的行和偏一点，压缩因子就变成 `γ(1+δ)`。**
4. **Day 31 的缺口补上了**：`V* ≤ T*V* ≤ T*²V* ≤ ...` 单调升，Banach 说极限是唯一不动点，
   所以 `V* ≤ V̄`；另一头 `V̄ = V^{π̄} ≤ V*`。**两头一夹，`V* = V̄`，`π̄` 就是最优策略。**
5. **`1/(1−γ)` 是 `e_k` 相对 `d_k` 的放大**，收紧一档是 `γ/(1−γ)`（`γ=0.9` 时 9 不是 10）。
   附带一条硬限制：**`γ` 大时 float64 的精度地板约 `R_max·eps/(1−γ)²`，
   `γ=0.999` 只能到 `5.6e-10`** —— 这不是慢，是做不到。
