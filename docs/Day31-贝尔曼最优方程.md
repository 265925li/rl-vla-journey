## 〇、今天的路线

昨天结束在一个「舒服」的位置：`V^π` 是一个线性方程组的解，有闭式 `(I − γP^π)⁻¹R^π`，一步就能算出来，还能拿采样去对拍。

今天要问的是一个**完全不同的问题**：

> 昨天那个 π 是**给定的**。谁给定了它？如果没人给定，最优的那个在哪？

答案看起来简单到可疑 —— 把 `Σ_a π(a|s)` 换成 `max_a`：

```
V^π(s) = Σ_a π(a|s) [ R(s,a) + γ Σ_{s'} P(s'|s,a) V^π(s') ]     ← 昨天
V*(s) = max_a       [ R(s,a) + γ Σ_{s'} P(s'|s,a) V*(s') ]      ← 今天
```

**一个符号。** 但今天就干这一件事，因为它同时改了三样东西：

| | 昨天 | 今天 |
|---|---|---|
| 方程类型 | 线性 | **非线性**（max 不是线性运算） |
| 能不能一步求解 | 能，`(I−γP^π)⁻¹` | **不能**，只能迭代 |
| 解唯一吗 | 唯一（可逆就有唯一解） | **唯一**（但理由完全不同） |
| 策略唯一吗 | 给定，不存在这个问题 | **不一定** |

四个格子里，只有「解唯一」这一格没变，而且变的理由也换了。

今天的路线按「证明缺口的形状」走：

1. 先把方程**推出来** —— 但只能推一半，另一半要等明天。**这个缺口就是明天的入口。**
2. 再问：换了这个符号，到底丢了什么（实验 A：10% 的错）
3. 然后回答「`V*` 到底是什么东西」（实验 B：它是所有 `V^π` 逐分量最大的那个）
4. 唯一性（实验 C）与不唯一性（实验 D）—— 一个能断言、一个不能
5. 最后一步：从 `V*` 出发贪心一次就够了（实验 E）—— 明天的种子

## 一、推导：只能推一半，而另一半正是明天的内容

### 1.1 起点：`V*` 是一个定义，不是结论

先把 `V*` 定义清楚，否则后面全是空话：

```
V*(s)  =  sup_π  V^π(s)          逐状态取上确界
```

注意两件事：

**① 上确界是对「策略」取的，不是对「动作」。** 差一个量级：动作只有 nA 个，策略有 `nA^nS` 个。

**② 它可能取不到。** 如果最优策略不存在（比如动作集无限、值函数不连续），上确界只是个界。但有限 MDP（状态有限、动作有限）里它一定取得到 —— 因为策略空间有限，最大值一定存在。**今天就只在有限 MDP 里说话。**

### 1.2 一步前瞻界（今天唯一真正证完的东西）

**引理（一步前瞻界）**：设 `V` 是任意一个 nS 维向量（不要求是任何策略的值），设策略 π 满足 `V^π ≤ V`（逐分量）。则

```
V^π(s)  ≤  max_a [ R(s,a) + γ Σ_{s'} P(s'|s,a) V(s') ]
```

**证明（两行，用的是昨天已经拿到的方程）：**

```
V^π(s) = Σ_a π(a|s) [ R(s,a) + γ Σ_{s'} P(s'|s,a) V^π(s') ]        ← 昨天的期望方程
       ≤ Σ_a π(a|s) [ R(s,a) + γ Σ_{s'} P(s'|s,a) V(s') ]          ← 用 V^π ≤ V，且 P ≥ 0
       ≤ max_a       [ R(s,a) + γ Σ_{s'} P(s'|s,a) V(s') ]          ← 加权平均 ≤ 最大值
```

第二步是关键：`P ≥ 0` 加上 `V^π ≤ V`，逐项放大之后求和还是 ≤。**如果 P 有负元素，这一步就废了。** 这是「转移概率」这个身份第一次真正被用到。

第三步是纯粹的算术：一组数的加权平均（权重非负、和为 1）不会超过它们的最大值。

**记这个右边为 `(T*V)(s)`。** 于是引理说：`V^π ≤ V ⟹ V^π ≤ T*V`。

### 1.3 单调性：`T*` 是个「不会把大小关系搞反」的算子

```
V ≤ U   ⟹   T*V ≤ T*U
```

同样两行：`P ≥ 0` 所以 `ΣP V ≤ ΣP U`，加上 R 不变，再 max（max 保序）。**这就是 max 的全部性质：保序，但不保线性。**

### 1.4 半边：`V* ≤ T*V*`

取任意策略 π。由 `V*` 的定义（上确界）有 `V^π ≤ V*`。用引理（取 `V = V*`）：

```
V^π ≤ T*V*        对**每一个** π 成立
⟹  V* = sup_π V^π ≤ T*V*
```

**这半边证完了。** 三行，没有用到任何新东西。

### 1.5 另一半：为什么今天证不完

要证 `T*V* ≤ V*`。给定 `T*V*`，可以做一步贪心拿到策略

```
π_g(s) = argmax_a [ R(s,a) + γ Σ P(s'|s,a) V*(s') ]
```

于是 `T^{π_g} V* = T*V*`（用 π_g 的算子作用在 `V*` 上，恰好等于取 max）。如果反复作用：

```
V*  →  T^{π_g}V*  →  (T^{π_g})²V*  →  ...
```

这个序列会收敛到 `V^{π_g}`（昨天的不动点迭代）。如果 `T^{π_g}V* ≤ V*`，由单调性整个序列单调不增，极限 `V^{π_g} ≤ V*` —— **但这是自动成立的**（`V*` 是上确界），推不出矛盾，也推不出 `T*V* ≤ V*`。

**卡住了。缺的是两件事，而且第二件依赖第一件：**

1. **`T*` 一定有不动点** —— 否则 `V* = T*V*` 这个式子本身就是空的
2. **从任意初值迭代都收敛到它** —— 否则上面那串 `V*, T*V*, T*²V*, ...` 停不下来

两件事都由同一个东西给出：`γ < 1` 时 `T*` 是**压缩映射**。这就是明天的 Banach 不动点定理。

```
⚠️ 今天不假装证完了。缺口精确地在这里：
   「V* ≤ T*V*」证完了，「T*V* ≤ V*」要等压缩映射。
   而有了压缩映射之后，其实不需要分别证两个方向 ——
   直接证「T* 的唯一不动点等于 V*」更省事，明天走那条路。
```

**这就是明天的全部动机。** 不是为了讲一个漂亮的数学定理，而是因为今天的证明差这一块砖。

### 1.6 于是方程先写下来，当「待证的猜想」

```
V*(s) = max_a [ R(s,a) + γ Σ_{s'} P(s'|s,a) V*(s') ]        ★
```

今天剩下的工作，是**用数值把 ★ 撑住**：

- 实验 B：解 ★ 得到的 `V*`，恰好等于穷举所有策略得到的最大值 → ★ 说的是同一个东西
- 实验 C：★ 的解唯一（三个初值都收敛到同一点）→ 它是个良定义的量
- 实验 E：从 ★ 的解贪心，得到的就是最优策略 → ★ 有用

三条数值证据不能代替证明，但它们能保证「即使证明明天才补，今天用的东西是对的」。

## 二、这一换，丢了什么

### 2.1 没有 `(I − γP)⁻¹` 了

昨天的可逆性证明靠的是：`(I − γP^π)` 是一个**矩阵**，`γ‖P^π‖∞ = γ < 1` 保证 `I − γP^π` 可逆。

今天 ★ 里的 `max_a` **不是一个矩阵**。它把「nA 个不同的线性映射」按状态逐点挑一个，挑哪一个是**依赖 V 的**。所以不存在一个固定的矩阵 `P*` 使得 ★ 变成 `(I − γP*)V = R*`。

```
⚠️ 但要说准：**「不存在固定的 P*」不等于「不存在线性方程」**。
   一旦你知道最优策略是哪个，★ 立刻塌回昨天的线性方程。
   真实情况是：V* 是 nA^nS 个线性方程组里挑出来的解（实验 B 会验证这一点）。
```

所以更准确的表述是：**max 破坏的不是「线性」，是「一步求解」。**

### 2.2 `max` 不能从 `Σ` 外面提出来（实验 A）

既然不能提，那自然有人会试。这就是实验 A 要打的靶子。

环境 HUB（`γ = 0.9`），只看 s0 这个岔路口。三个动作：

| 动作 | 含义 | `R` | `γΣPV*` | `Q = R + γΣPV*` |
|---|---|---|---|---|
| a0 | 直接去金矿 | 0 | **72.0000** | 72.0000 |
| a1 | 直接去陷阱，但立刻 +10 | **10.0000** | 0 | 10.0000 |
| a2 | 一半一半（0.5 概率回 s0） | 5.0000 | 69.5455 | **74.5455** |

```
正确： V*(s0) = max_a (R + γΣPV*) = 74.5455     ← 挑 a2
天真： max_a R + max_a γΣPV*     = 82.0000     ← 挑 a1 和 a0
差 7.4545（10.0%）
```

**天真算法把 a1 的奖励和 a0 的未来拼在了一起 —— 那不是任何一个动作。** 它算出来的东西对应一个在这个世界里根本不存在的策略。

而且它**必然偏大**：两个 max 各自取到最大，只会高不会低。所以这个错不会立刻崩，它只是让 Q 值系统性偏高 —— **这正是 W6 里 Q-Learning 高估偏差（overestimation）的来源**，今天先记着。

一句话总结这个错：

```
max_a ( R_a + γG_a )   ≠   max_a R_a  +  γ max_a G_a
        ↑ 一个 a 从头用到尾          ↑ 允许中途换人
```

左边是「选一个动作并承担它的全部后果」，右边是「挑最好的奖励搭配最好的未来」。**RL 的全部困难都在这个区别里。**

### 2.3 ⚠️ 最优动作是 a2 —— 既不是奖励最大的，也不是未来最好的

这一点比 10% 的误差更值得看：

- a1 奖励最高（+10），但未来最差（0）→ Q = 10
- a0 未来最好（72），但当前奖励是 0 → Q = 72
- **a2 两个都中等 → 反而 Q 最大（74.5455）**

所以「贪心」这个词容易误导：最优动作不是「看哪个奖励大」，也不是「看哪条路好走」，是**看两者之和**。而且和可以比任何一个分量都大 —— a2 的 74.5455 比 a0 的 72 和 a1 的 10 都大。

### 2.4 手算：820/11 从哪来

`74.5455` 不是整数，因为 a2 有 0.5 概率**回到 s0**，于是 `V(0)` 的式子里含 `V(0)` 自己。这就是自引用，解法是解一个一元方程：

```
V(0) = 5 + 0.9 · ( 0.5·V(0) + 0.5·V(1) )
     = 5 + 0.9 · ( 0.5·V(0) + 0.5·80 )          ← V*(1) = 80，去金矿后自循环 8 每步
     = 5 + 0.45·V(0) + 36
0.55·V(0) = 41
     V(0) = 41/0.55 = 4100/55 = 820/11 = 74.545454...
```

**注意脚本里 `γΣPV*` 那一列用的是已经收敛的 `V*`**，也就是说「`V(0)` 里面含 `V(0)`」这个循环已经被迭代解掉了。值迭代做的正是这件事：拿上一轮的 `V(0)` 当这一轮的输入，直到自洽。

## 三、`V*` 到底是什么：实验 B

### 3.1 穷举 27 个策略

HUB 有 3 状态 3 动作，确定性策略共有 `3³ = 27` 个。对每一个，用昨天的公式解出 `V^π`，然后逐分量取最大：

```
逐分量取最大： [74.545454545, 80., 0.]
值迭代的 V* ： [74.545454545, 80., 0.]
差 8.100e-12              ← 1e-12 的收敛容差量级，就是 0
```

**`V* = max_π V^π`（逐分量）。**

这个等式值得单独记一次，因为它把「最优」从形容词变成了一个**可以算出来的东西**。之前 `V*` 的定义是「所有策略值函数的上确界」—— 这定义是循环的，因为策略集合大得数不清。实验 B 说的却是：这个上确界等于一个**具体的、由 ★ 解出来的向量**。

### 3.2 ⚠️ 一个真实的坑：冗余动作 ≠ 策略不唯一

27 个里，达到 `V*` 的有 **4 个**：

```
[(2,0,0), (2,0,2), (2,2,0), (2,2,2)]
```

第一眼看像「最优策略有 4 个」。**但不是。** 按 `(P^π, R^π)` 去重后只剩 **1 组**。

原因是 HUB 里 s1 的 a0 和 a2 转移、奖励**逐位相同**（s2 的 a0/a2 也是）。这种叫**冗余动作** —— 换个编号，策略没换。

```
⚠️ 不区分「冗余」和「不唯一」，会把一个平庸的环境误判成
   「我的算法不稳定」。下面实验 D 才是真平局。
```

这条在工程上很常见：你给动作加了同义选项（两个都叫「前进」），或者某些状态下两个动作被环境映射成同一个转移 —— 此时策略在它们之间随机跳，**看起来像不稳定，其实是同一个策略**。

### 3.3 DP 存在的理由，用数字说

- HUB：27 个策略，穷举 0.01 秒
- 10×10 GridWorld（4 个动作）：`4^100 ≈ 1.6 × 10⁶⁰` 个策略

第二个数字给个尺度：**假设你每秒检查 10 亿个策略，从宇宙大爆炸查到今天（4.36 × 10¹⁷ 秒），总共只能查 4.4 × 10²⁶ 个 —— 还差 3.7 × 10³³ 倍。**

所以可以下一个硬结论：**凡是靠穷举策略来做的事，在真实规模上都不可能。**

所以 DP 的全部工作可以一句话概括：

> 不做穷举，直接挑对那个策略。

怎么挑对？两种挑法就是 Day 34/35 的策略迭代和值迭代。今天只把「存在一个对的策略」这件事钉住。

## 四、`V*` 唯一（实验 C）

### 4.1 三个初值，同一个终点

| 初值 | 轮数 | `V(0)` | `V(1)` | `V(2)` |
|---|---|---|---|---|
| 全 0 | **284** | 74.545454545 | 80.000000000 | 0.000000000 |
| 全 1000 | 307 | 74.545454545 | 80.000000000 | 0.000000000 |
| 全 -1000 | 308 | 74.545454545 | 80.000000000 | 0.000000000 |

三个终点之间的最大差 `1.636e-11` —— **同一个点。**

所以 `V*` 与初值无关。这不只是好消息，它是「值迭代可以随便初始化」这个做法的**全部依据**：你不知道 `V*` 在哪，从哪出发都行。

### 4.2 ⚠️ 停止判据宽松了 `1/(1−γ)` 倍，而且不报警

轮数 284 / 307 / 308 里有两条信息。

**第一条：初值影响很小，而且是对数级。**

从 -1000 起步时，相邻两轮之差是 `108 × 0.9^k`；从 0 起步是 `8 × 0.9^k`。系数大了 **13.5 倍**，轮数只多 **25** 轮 —— 因为轮数随系数是 `log` 增长：`log(13.5)/log(1/0.9) = 24.7`。实测 308 − 284 = 24。

**第二条比第一条重要得多：这个「284 轮收敛」是乐观的。**

脚本的停止判据是 `|V_{k+1} − V_k| < 1e-12`（相邻两轮之差），不是 `|V_k − V*| < 1e-12`（到真值的距离）。

**直接实测**（拿解析解 `[820/11, 80, 0]` 当基准，不是拿迭代结果当基准）：

```
全 0 那条在 k = 284 停下，相邻差 8.953e-13  ✅ 低于判据
但那一刻离真值还有      8.086e-12          ❌ 比 1e-12 大 8.1 倍
```

差 8.1 倍，而 `1/(1−γ) = 10` —— 同一个数，差的那一点是因为最大分量换过一次人（∞-范数只取最大那个）。

为什么正好是这个倍数：

```
|V_k − V*|       ≈  80 × 0.9^k     ← 到真值的距离
|V_{k+1} − V_k|  ≈   8 × 0.9^k     ← 相邻差
                        ↑ 系数正好差一个 (1−γ)
```

因为 `V_{k+1} − V_k = (T*V_k − T*V_{k-1})`，而压缩性给出 `|T*V_k − T*V_{k-1}| ≤ γ|V_k − V_{k-1}|`。累积的误差是等比级数，和是 `1/(1−γ)` 倍。

```
⚠️ 「值迭代收敛了」这句话，比你想象的乐观 1/(1−γ) 倍。
   γ=0.9 时是 10 倍（实测 8.1），γ=0.99 时是 100 倍，γ=0.999 时是 1000 倍。
   **你不会收到任何提示。**
```

这个倍数不是巧合，Day 32 会给出它的严格来源。它同时是后面很多东西的同一个根：PPO 里 GAE 的 `λ`、DQN 里 target network 的软更新、eligibility trace 的衰减 —— 都是在对 `1/(1−γ)` 这个放大做补偿。

**今天要带走的操作结论**：写值迭代时，如果想知道「我真的收敛到 1e-12 了吗」，判据应该是 `|V_{k+1}−V_k| / (1−γ)` 而不是裸的相邻差。或者反过来：**你报的精度数字，前 `log₁₀(1/(1−γ))` 位是假的。**

## 五、`V*` 唯一，`π*` 不一定（实验 D）

### 5.1 TIE 环境是反推造出来的

要演示平局，最快的方法是**倒着构造**：先定 `V* = [5, 2]`、`γ = 0.5`，再解出 R，让 s1 的两个动作 Q 值恰好相等。

```
s1·a0（回到 s0）： Q = R₁₀ + 0.5·V*(0) = R₁₀ + 2.5 = 2   →  R₁₀ = −0.5
s1·a1（留在 s1）： Q = R₁₁ + 0.5·V*(1) = R₁₁ + 1.0 = 2   →  R₁₁ = +1.0
```

实测：

```
a0（回到 s0）：R = −0.50 + 0.5·ΣPV* = 2.0000
a1（留在 s1）：R = +1.00 + 0.5·ΣPV* = 2.0000
```

**两个动作的 Q 都是 2.0000，但一个往 s0 走、一个留在 s1。** 转移完全不同，价值一模一样。

四个确定性策略里，两个达到 `V*`：

| 策略 | `V^π(0)` | `V^π(1)` | 是 `V*` 吗 |
|---|---|---|---|
| (0, 0) | 5.000000000 | 2.000000000 | ✅ |
| (0, 1) | 5.000000000 | 2.000000000 | ✅ |
| (1, 0) | 1.142857143 | 0.071428571 | — |
| (1, 1) | 2.000000000 | 2.000000000 | — |

两个最优策略的 `V^π` **完全一样**，但走法不同。

### 5.2 所以断言要断言值

```
✅ V* 唯一 —— 可以断言
❌ π* 唯一 —— 不能断言
```

今天所有实验的断言都只碰 `V*`。这条纪律在写测试时是硬约束：如果你写 `assert policy == expected_policy`，遇到平局就挂，而挂的不是代码。

### 5.3 工程含义：平局不精确，但近似平局到处都有

我是把 R 反推出来凑出这个平局的 —— 小数点后两位就合上了，真实环境里不会有这么巧的事。

**但「近似平局」到处都是**：两个动作的 Q 差 0.001。于是：

- 贪心策略会在它们之间**来回跳**（浮点误差一变，argmax 就换人）
- 看起来像「训练不稳定」，**其实是两个都对**
- 如果此时你用「策略变了多少次」当收敛判据，会永远不收敛

所以遇到「策略抖动」，先量一下 `Q` 的差距，再判断是 bug 还是平局。这个诊断顺序能省掉大量时间。

## 六、`Q*` 与一步贪心（实验 E）

### 6.1 引入 `Q*`

★ 里那个方括号值得单独起个名字：

```
Q*(s,a)  =  R(s,a) + γ Σ_{s'} P(s'|s,a) V*(s')          ← 动作价值
V*(s)    =  max_a Q*(s,a)                                ← 于是 ★ 变成一行
π*(s)    =  argmax_a Q*(s,a)                             ← 而且最优策略立刻有了形状
```

**第三个式子是今天最实用的产出**。它说：最优策略永远是「贪心的」—— 只要你手里有准确的 `Q*`，选最大的那个动作就对了，不需要试探、不需要权衡、不需要探索。

这正是 W6 里 Q-Learning 的全部内容：**它学的就是 `Q*`，学会了就贪心。** `Q` 这个字母就是从这里来的。

### 6.2 实验 E：从 `V*` 贪心一次就够

```
环境      贪心得到的策略     它的 V^π 与 V* 之差     是不是最优
CHAIN        (1, 0)           5.196e-13              ✅
TIE          (0, 0)           9.095e-13              ✅
HUB        (2, 0, 0)          8.100e-12              ✅
```

三个环境都是：**从 `V*` 贪心一次，直接得到最优策略**，`V^π` 和 `V*` 差 0（1e-12 量级是数值容差）。

这件事叫**策略改进定理**：

```
对任何策略 π，用 V^π 做贪心得到的 π' 一定满足   V^{π'} ≥ V^π
```

取 π 已经是最优时，等号成立，所以你贪心一次还是它。Day 34 会正经证它。

### 6.3 两个方向，别搞混

| | 在什么空间里动 | 谁固定 | 一步做什么 |
|---|---|---|---|
| **策略评估**（昨天） | 值空间 | 策略固定 | `V ← T^π V` |
| **策略改进**（今天） | 策略空间 | 值固定 | `π ← greedy(V)` |

值迭代把两者**交替**着做（`V ← T*V` 其实同时做了两件事），策略迭代把它们**分开**做。明天会看到两者都是同一个压缩映射的不同写法。

### 6.4 ⚠️ 这条只在「能精确算出 `V^π`」时成立

实验 E 的三个 ✅ 有一个共同前提：我有 `P` 和 `R`，所以 `Q*(s,a)` 能算到 1e-12。

**W6 里你拿不到 `P`。** `Q` 只能估，估偏了贪心就选错。而且 2.2 节那个「天真算法必然偏大」的性质在这里会回来：`max_a` 作用在**有噪声的** `Q` 估计上，会系统性地挑到被高估的那个 —— 这就是 **overestimation bias**，DQN 的 Double DQN、PPO 的 clip 都在处理它。

```
今天的结论：max 在精确世界里是免费的；
           在估计世界里，它是个偏差放大器。
```

## 七、今天要记住的三个边界

### 7.1 `V*` 唯一 ≠ `π*` 唯一

已在 §五。断言值，不断言策略。

### 7.2 「`max` 破坏线性」要说准

破坏的是**一步求解**，不是「存在线性方程」。给定策略后仍然线性（昨天），所以策略迭代的每一步仍然要解一个线性方程组。

### 7.3 值迭代的「收敛」比你以为的宽松 `1/(1−γ)` 倍

已在 §4.2。这是今天唯一一个会**悄悄**错掉的地方 —— 前两个错了会报错或断言失败，这个错了什么都不发生，只是你的数字离真值还有一段距离。

### 9.2 今天真正学到的东西（按重要性排）

**第一：`max` 和 `Σ` 的区别不是「取最大 vs 取平均」，是「能不能拆分」。**

`Σ` 可以逐项拆开再拼回去 —— 这就是线性，也是昨天能一步求解的全部原因。`max` 不行，它只满足 `max(x+y) ≤ max x + max y`，而且等号经常不成立。实测那 10% 就是不等号的宽度。

这一条在 RL 里反复出现：DQN 的目标里那个 `max`、PPO 的 clip（本质是 `min`）、分布式 RL 的 `max` 算子。**凡是有 `max` 的地方，都不能按线性去推。**

**第二：一个证明缺口可以告诉你明天该学什么。**

如果我只告诉你「压缩映射很重要」，那是个抽象的动机。今天的情况是：**我在 §1.5 卡住了，缺的正好是压缩性。** 这个缺口是具体的、可指认的。带着缺口去学，比带着目录去学有效得多。

以后每一周都可以这样：先推到推不动，再学补丁。

**第三：`1/(1−γ)` 这个因子会以各种面目反复出现。**

今天它是「停止判据的乐观倍数」。Day 29 它是「`|G_t| ≤ R_max/(1−γ)` 的界」。Day 30 它是 `(I−γP^π)⁻¹ = Σγ^k(P^π)^k` 这个级数收敛到多远。W6 它会变成「TD 的有效视野长度」。**同一个数，四个身份。** 见到它就想起「无限期折扣的等效长度」。

### 9.3 我这次自己犯的错

**① 预演时把收敛轮数的系数算错了。**

我一开始写的是「从 -1000 起步，系数 1080，要 740 轮」。实测 308 轮。

原因：我把「与真值的距离」的系数（1080）当成了「相邻差」的系数。相邻差是 `108 × 0.9^k`，差 10 倍，轮数差 `log(10)/log(1/0.9) ≈ 22` 轮。

修的时候我没直接改成 308，而是把两个系数（8 和 108）都写成公式、再和实测对账 —— 对上了才写进讲义。**「算过的数」和「看起来合理的数」长得一模一样，只有对账能分开。**

**② ⚠️ 我用迭代结果当「真值」算误差 —— 这是循环论证。**

第一版验证 §4.2 时，我拿 `value_iteration()` 返回的向量当基准，去算「离真值多远」。结果 k=284 时误差是 `0.000e+00`（因为基准和被测是同一条轨迹），而 k=304 时误差反而变成 `6.6e-12`。

**误差随迭代变大** —— 这个荒谬的结果才让我发现基准是错的。换成解析解 `820/11` 之后，数字立刻正常：单调下降，284 轮时 8.086e-12。

```
⚠️ 拿一个「也是算出来的」东西当基准，你测的是两次计算的差，不是误差。
   基准必须来自独立的来源（解析解、闭式、或另一条原理上不同的路）。
   这和 Day 30 实验 C 拿「直接解」对拍「迭代」是同一个道理。
```

**③ 实验 B 的 4 个「最优策略」我差点当成「策略不唯一」写进去。**

那是 HUB 里 s1 的 a0/a2 完全相同造成的**冗余动作**。加了一步按 `(P^π, R^π)` 去重，才露出真相：只有 1 组。

如果没发现，今天的结论会变成错的 —— 而且是个**看起来很漂亮**的错（「看，最优策略有 4 个！」）。这类错比数字错更危险，因为它会变成一条你以后一直相信的「知识」。
