## 三、跨天复用的关键技术结论

这些是**踩过的坑**，比任何教程都值钱。

### 环境类

- 路径含空格（`work Buddy`），PowerShell 里**必须加引号 + 开头 `&`**
- `.gitignore` 写 `data/` 会匹配**任意层级**，吞掉 `src/data/` → 必须写 `/data/`
- 相对路径 `data_dir` 依赖 cwd，在 `scripts/` 里跑会把 MNIST 下到 `scripts/data/`（真的多存了 64 MB）→ 已在 `load_config()` 里按项目根解析成绝对路径

### 数值类

- **fp16 的 exp 溢出阈值只有 11.1**（float32 是 88.7）→ 混合精度训练必须用 log-sum-exp
- **双 softmax 的 loss 下界**：10 类 `-ln(e/(e+9)) = 1.4612`；实测模型上加一层差 **48 倍**（0.0307 → 1.4837），且不报错
- **交叉熵对 logits 的梯度天生有界**：`(p − onehot)/N`，每行和为 0、绝对值 ≤ 1/N → 这是它比 MSE+sigmoid 好训的根本原因
- **浮点误差会被 SGD 放大**：同 seed 下 `ce` vs `myce`，首轮 train_loss 前 6 位全同，次轮 val_loss 差 `3.6e-03`（放大 36 万倍），test 差 3 条。→「完全一致」应表述为「**单步一致、多步分叉、终值差远小于统计噪声**」
- **换实现的影响取决于「换了多深那一层」**（Day 17 实测）：换调用位置（`torch` Linear → 手写，同一个 cuBLAS kernel）起始误差 `~1e-8`，2 epoch 后 val_loss 差 `6.66e-04`；换整条数值路径（`ce` → 手写 softmax，`log(softmax)` vs 融合的 `logsumexp`）起始误差 `~1e-7`，差 `3.6e-03`。**差一个数量级 → 放大后差 5 倍**
- **`train_loss` 的分叉比 `val_loss` 小得多**：前者是 844 步的平均（误差正负抵消），后者是在已分叉参数上算的结果。实测同一次对比里 `6.00e-06` vs `6.66e-04`，**差 111 倍**。**平均会抵消噪声，结果不会**

### 训练类

- **`weight_decay` 与 `momentum` 互相放大**：`1/(1-0.9)=10` 倍。yaml 里的数字不等于实际力度，换优化器时同一个 wd 效果完全不同
- **一个超参数只测一个点 = 什么都没测出来**（我犯过：只测 wd=5e-4 就说"正则化没用"，补扫后结论反了一半）
- **MNIST + MLP 天花板 ≈ 98.0–98.1%**：hidden 512 到 0.9818、wd 最优 0.9812，均不显著 → 想再提升必须换架构（CNN）
- **正则化是刹车不是方向盘**：只治过拟合，本身是欠拟合成因之一；「用多少」比「用不用」重要
- **早停判据选错会得到相反结论**：acc 判据 9 轮停（0.9782）vs loss 判据跑满 10 轮（0.9800）。根因是验证集 6000 条，**正确 1 条 = 0.0167%**，acc 分辨率太粗

### 工程类

- **重构的验收标准是「输出一个比特都没变」，不是「代码更整齐」**（Day 18 实测）：同 seed 下 `history` / `test` / `best_val_acc` / `final_wnorm` 四项逐字段相同。能这样验的前提是 Day 13 那个决定 —— **耗时不能写进 `history.json`**
- **重构会让代码变长**：`train_mnist.py` 546 行 → 40 行薄壳 + 1008 行分 8 个模块，总行数涨了一倍。重构的收益在改动面，不在行数
- **「通用模板」的实质是注册表**：`build_model(name, cfg)` + `--set k=v` 兜底。判断标准只有一条 —— **换实验时，`cli.py` 和 `trainer.py` 要不要改？**
- **凡是影响训练结果的开关，必须落进 `config.yaml`**（Day 18 修的真 bug）：`es_metric` 曾只活在 argparse 里，导致按 loss 和按 acc 早停两次跑的 `config.yaml` 一模一样
- **`config.py` 里不能写死模型名列表**：那会逼你每加一个模型就去碰「所有实验都依赖」的文件。名字校验交给注册表，它的报错还能带上可选列表
- **两个入口必须共用同一个 `main()`**：`train.py` 和 `train_mnist.py` 各写一份参数表，迟早漂移，症状是「同一命令两个结果」
- **「为了副作用而 import」是正常的**：`import src.engine.builtin` 就是为了触发注册。删掉它，`build_model("mlp")` 会报「未知模型」
- **注册表必须拒绝重复注册**：静默覆盖的后果是「以为跑 A，实际跑 B」，全程无提示

### 自定义 `autograd.Function` 的三个静默坑

1. **存中间量而非输入** → 一阶导对、二阶导全 0（`gradcheck` 过、`gradgradcheck` 挂）
2. **`ctx.p = p` 而非 `save_for_backward`** → 原地改不报错，第一次 backward 完全正确、第二次才错
3. **漏乘 `grad_out`** → 单独测时 `grad_out` 恰好 = 1.0，看不出问题；上游一有缩放就少乘系数
