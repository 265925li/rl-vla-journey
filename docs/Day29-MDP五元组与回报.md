## 一、先把问题摆出来，别从符号开始

教科书从 `(S, A, P, R, γ)` 开始讲，那是**结论的排版顺序**，不是理解顺序。
理解顺序是反的：先有一个**具体的麻烦**，然后发现描述它必须引入这五个东西。

### 1.1 一个 3×3 的格子

```
┌───┬───┬───┐
│ S │   │   │
├───┼───┼───┤
│   │ █ │   │         S = 起点      G = 终点（+1）
├───┼───┼───┤         █ = 陷阱（−1，进去就结束）
│   │   │ G │         每走一步 −0.01（"时间有成本"）
└───┴───┴───┘
```

一个 agent 站在 S。它能上下左右走，撞墙就原地不动。
问：**它应该怎么走？**

要回答这个问题，必须能把「怎么走」翻译成数学。翻译的过程会强迫你说清五件事：

1. **世界有多少种情形？** —— 9 个格子（+ 2 个终止态）。→ `S`
2. **它能做哪些事？** —— 上、下、左、右。→ `A`
3. **做了之后世界怎么变？** —— 往右走一定到右边那格吗？如果地滑呢？→ `P`
4. **什么算好、什么算坏？** —— 到 G 给 +1，进陷阱给 −1，每步 −0.01。→ `R`
5. **未来的好处要不要打折？** —— 现在拿 1 分和 10 步后拿 1 分，一样吗？→ `γ`

**这就是五元组的来历。它不是一个定义，是五个必须回答的问题。**

## 二、马尔可夫性：五元组里唯一的假设

五元组里 `S`、`A`、`P`、`R`、`γ` 都是「描述」，只有一条是**假设**，
而且是整个 RL 唯一的核心假设。它藏在 `P` 的写法里。

### 2.1 定义

`P` 写成 `p(s', r | s, a)` 的时候，你已经默认了：

> **给定现在的 `s` 和 `a`，下一步的 `(s', r)` 与更早的历史无关。**

严格写：

```
p(s', r | s, a) ≡ P(S_{t+1}=s', R_{t+1}=r | S_t=s, A_t=a,
                      S_{t-1}, A_{t-1}, ..., S_0, A_0)
```

左边没有历史，右边有历史，而等式成立 —— **这就是马尔可夫性**。

### 2.2 它排除了什么

它排除的是「记住过去才有用」的情形。举例：

- **成立**：下棋。棋盘当前摆法决定一切，怎么走到的无关。
- **不成立**：二十一点。你现在手里 15 点，**还要知道已经发了几张 A**
  才知道该不该要牌。牌堆的组成依赖历史。
- **不成立**：走路时你的速度。位置相同但速度不同，下一步能去哪不一样。
  → 修法：把「速度」塞进状态，`s = (位置, 速度)`。塞进去之后又成立了。

注意第二种修法：**马尔可夫性不是世界的性质，是你描述方式的性质。**
世界永远是有历史的；你能不能把它压成「只看现在」，取决于你把什么算进 `s`。

### 2.3 状态定义错了会发生什么（实测）

`scripts/probe_mdp.py` 的实验 E 把这件事做成了数字。

一条两状态的链，只有一个动作：

```
A --奖励 1--> B --奖励 0--> A --奖励 1--> B ...
```

确定性交替，`γ = 0.9`。精确值（实验 C 算出来的）：

```
V(A) = 5.263158
V(B) = 4.736842
```

现在做一个「状态抽象」：让观测只看**颜色**，而 A 和 B 是同一个颜色 `c`。
参数层面看，观测只有一个取值 `c`。那 `V(c)` 是多少？

| 观测到的 | 隐藏的真实状态 | `E[G | 观测]` |
|---|---|---|
| `c` | A | **5.263158** |
| `c` | B | **4.736842** |

**同一个观测，两个不同的期望回报，差 0.526316。**

所以 `V(c)` 没有定义。不是「算不准」，是**根本不存在这个数**。

### 2.4 这个差能不能靠调 `γ` 抹掉（实测，顺手证了个闭式）

直觉上会想：「`γ` 小一点，看得近一点，是不是两个就差不多了？」算一下就知道不行。

代数上先推（这一步是写讲义时才算的，一开始我猜错了方向）：

```
V(A) − V(B) = 1/(1−γ²) − γ/(1−γ²) = (1−γ)/(1−γ²) = 1/(1+γ)
```

`γ` 越大差越小，但 `γ→1` 时它趋近 **0.5**，`γ→0` 时是 1。
**所以这个差永远落在 (0.5, 1] 里，不可能变小到 0。**

逐点实测（实验 E）：

| `γ` | `V(A)−V(B)` 实测 | `1/(1+γ)` | 差 |
|---|---|---|---|
| 0 | 1.000000 | 1.000000 | `0.000e+00` |
| 0.5 | 0.666667 | 0.666667 | `0.000e+00` |
| 0.9 | 0.526316 | 0.526316 | `1.110e-16` |
| 0.99 | 0.502513 | 0.502513 | `1.776e-15` |
| 0.999 | 0.500250 | 0.500250 | `2.387e-14` |

最大偏差 `2.387e-14`，解析式对得上。

**结论比「差值不为 0」更强**：它有个 `0.5` 的下界。
所以「马尔可夫性被破坏」不是一个能靠调参缓解的程度问题，
**它是「有没有」的问题** —— 观测一旦丢了信息，`V` 就不存在，一步都省不掉。

> 顺带一条方法论：我第一版讲义在这里写的是「`γ` 改成 0.5，差值会变得小得多」。
> 那是**顺着直觉编的，没算**。实算发现方向反了 —— γ=0.5 时差是 0.667，比 0.526 还大。
> 这条错误要是留在讲义里，你以后调 `γ` 会照着错的方向试。
> **凡是要写进讲义的数字，先算一遍或跑一遍。**

```
⚠️ 状态不是"你能看到的东西"，状态是"决定未来的所有信息"。
   A 和 B 看到的一样，但它们的未来不一样，所以它们是两个状态。
```

这句是整周最容易糊过去的地方。工程含义很硬：
**你在设计特征的那一刻，就已经在决定马尔可夫性成不成立**，
而不是等算法跑崩了再回头查。

Day 33 写 GridWorld 时，「状态 = 格子坐标」看起来天经地义 ——
但如果你为了「泛化」把坐标去掉、只留「周围有没有墙」，
就立刻退化成今天这个实验，`V` 直接不存在。**这不是理论洁癖，是能当场测出来的。**

## 三、五元组，逐个说清

### 3.1 `S`：状态集

- **有限**还是**连续**：GridWorld 是有限（9 个），MuJoCo 的机器人姿态是连续。
  有限时可以用表格存 `V`（本周全部用这个），连续时必须用函数逼近（W7 之后）。
- **终止态算不算状态**：算。终止态的 `V ≡ 0`（没有未来），
  但它在 `P` 里必须能被「进入」，否则轨迹停不下来。

### 3.2 `A`：动作集

- 可以是有限（上/下/左/右）、也可以连续（关节力矩）。
- **关键区分**：`A` 是 agent 能选的，`S` 是 agent 不能选的。
  凡是「agent 决定不了但影响未来」的量，都属于 `S`（见 2.2 的速度）。

### 3.3 `P`：转移

标准写法是**四参数联合分布**：

```
p(s', r | s, a)          从 s 做 a，进入 s' 并拿到 r 的概率
```

注意它同时给出了「去哪」和「拿多少」，**是一个东西不是两个**。

两个必须满足的约束：

```
Σ_{s'} Σ_r p(s', r | s, a) = 1        对所有 (s, a)          归一
p(s', r | s, a) ≥ 0
```

从它派生出两个常用量：

```
p(s' | s, a) = Σ_r p(s', r | s, a)                    状态转移
r(s, a)      = Σ_{s'} Σ_r r · p(s', r | s, a)         期望即时奖励
```

**注意第二个式子里 `r` 是求和里的权重**，不是下标 —— 这是「期望奖励」，
不是「某个确定的奖励」。很多教材写成 `R(s,a)` 而不说明它是期望，这里先记住。

### 3.4 `R`：为什么不能和 `P` 合并

这是今天第一个容易糊的地方。常见说法是「`R` 是 `P` 的一部分，合并成 `p(s',r|s,a)` 就行」。
**合并会丢信息**，三个理由：

1. **奖励通常不依赖 `s'`**。「进陷阱 −1」这个奖励，不管从哪进都是 −1。
   把它写进联合分布，等于给每条 `(s,a,s')` 都存一份重复的数字。
   能省的结构应该省，否则表格存不下。
2. **很多任务只给了 `r(s,a)`（确定性奖励），`P` 是随机的**。
   这时联合分布仍是「`P` 乘一个 delta」，但你写代码时要先拆开再乘，
   合并形态反而多一步。
3. **最实际的**：写 `P` 的时候你只关心「去哪」，写 `R` 的时候你只关心「值多少」。
   **两件事分开写，错了能分开定位。**

记号上本周采用：

```
P[s, a, s']        形状 (nS, nA, nS)        确定性奖励时够用
R[s, a]            形状 (nS, nA)            期望即时奖励
```

> ⚠️ Day 33 的坑提前说：`P` 的形状定下来之后**全程别改**。
> `(nS, nA, nS)` 还是 `(nS*nA, nS)`，定哪个都行，但后面每天都要用它，
> 改一次就要重推一遍所有索引。

### 3.5 `γ`：一个符号，三个身份

`γ ∈ [0, 1)`。它有三种完全不同的解释，**都要知道**，因为不同场合会用到不同那个：

| 身份 | 说法 | 什么时候用 |
|---|---|---|
| **收敛保证** | `γ<1` 让总回报有上界，让贝尔曼算子成为压缩映射 | Day 32 证收敛 |
| **时间偏好** | 现在的一分钱比十步后的一分值钱 | 讲直觉、设计奖励 |
| **终止概率** | 等价于「每步以 `1−γ` 概率随机死掉」 | 把无限期问题变有限期 |

第三个身份值得多说一句，因为它不显然：如果每步以 `1−γ` 概率结束，
则「还能活 k 步」的概率是 `γ^k`，而 `Σ_k γ^k · r` 正好就是折扣回报。
**所以「打折」和「可能突然死掉」在数学上是同一件事。**
这个等价在 W7 讲 TD(λ) 和 GAE 时会直接拿来用。

**实测它有多大的杠杆**（实验 A，同一环境只改 `γ`）：

| `γ` | `V(A) = 1/(1−γ²)` | 矩阵解 | 界 `R_max/(1−γ)` | 占界比例 |
|---|---|---|---|---|
| 0 | 1.000000 | 1.000000 | 1.0000 | 1.0000 |
| 0.5 | 1.333333 | 1.333333 | 2.0000 | 0.6667 |
| 0.9 | **5.263158** | 5.263158 | 10.0000 | 0.5263 |
| 0.99 | **50.251256** | 50.251256 | 100.0000 | 0.5025 |
| 0.999 | **500.250125** | 500.250125 | 1000.0000 | 0.5003 |

**同一个环境，只改 `γ` 从 0.9 到 0.999，值函数从 5.26 变成 500.25 —— 翻了 95 倍。**

所以 `γ` 不是「超参」这个级别的词能概括的，**它决定这个任务看多远**。
调 `γ` 相当于把「眼前」的定义改掉。

## 四、轨迹与回报

### 4.1 轨迹的概率能连乘 —— 马尔可夫性的直接用途

一条长度 T 的轨迹 `τ = (s_0, a_0, r_1, s_1, a_1, r_2, ..., s_T)`。
它的概率（在策略 `π` 下）：

```
p(τ) = p(s_0) · Π_{t=0}^{T-1} π(a_t | s_t) · p(s_{t+1}, r_{t+1} | s_t, a_t)
```

**这个连乘就是马尔可夫性换来的全部好处。**

如果没有马尔可夫性，每一项都要写成 `p(s_{t+1}, r_{t+1} | s_t, a_t, s_{t-1}, a_{t-1}, ...)`，
参数数量随 T 爆炸，什么也算不出来。有了它，一个 `(nS, nA, nS)` 的表就够描述任意长的轨迹。

后面所有算法的「期望」都是对这个 `p(τ)` 求的。
Day 30 推贝尔曼方程时，你只是在把 `p(τ)` 的求和拆成「第一步 + 剩下的」。

### 4.2 回报 `G_t` 的定义

```
G_t = R_{t+1} + γ R_{t+2} + γ² R_{t+3} + ... = Σ_{k=0}^{∞} γ^k R_{t+k+1}
```

**注意下标：`G_t` 从 `R_{t+1}` 开始。** 这不是笔误 ——
`G_t` 是「站在 t 时刻对未来的总收益」，而 `R_{t+1}` 是「做了 `A_t` 之后立刻拿到的」。
`R_t` 已经在 `G_{t-1}` 里算过了。

这个下标偏移在写代码时是 bug 第一来源。表格实现里，
`R[s, a]` 表示「在 s 做 a 之后拿到」，所以 `G_t` 用 `R[s_t, a_t]`。

### 4.3 手推：`G_t = R_{t+1} + γ G_{t+1}`

这一步要自己写出来，不能看。只有两行：

```
G_t  = R_{t+1} + γ R_{t+2} + γ² R_{t+3} + ...
     = R_{t+1} + γ (R_{t+2} + γ R_{t+3} + ...)
     = R_{t+1} + γ G_{t+1}
```

第一行是定义，第二行是**提取公因子 `γ`**，第三行是**认出括号里就是 `G_{t+1}` 的定义**。

**这条恒等不是新假设，它就是定义式移了个项。** 但它是全部 RL 的种子：

```
Day 30  贝尔曼期望方程   = 对这条恒等式两边取 E[·|S_t=s]
Day 31  贝尔曼最优方程   = 把 E 换成 max
Day 36  TD 更新          = 把 E 换成一次采样
PPO 的 advantage         = 由它展开出的 n 步估计
```

实测（实验 B，5 条 20 步轨迹，γ=0.9）：

```
|G_t − (R_{t+1} + γG_{t+1})| 在所有轨迹、所有 t 上的最大值 = 0.000e+00
```

严格相等。因为它本来就是恒等式 —— **这一条不需要"验证"，验证只是确认自己没写错下标**。

### 4.4 回报的上界：`|G_t| ≤ R_max/(1−γ)`

两行证明，自己推：

```
|G_t| ≤ Σ_k γ^k |R_{t+k+1}|          （三角不等式）
      ≤ R_max · Σ_k γ^k              （每项绝对不超过 R_max）
      = R_max / (1 − γ)              （等比级数，γ<1）
```

实验 A 那张表的最后一列就是 `V(A) / (R_max/(1−γ))`，全部 ≤ 1（0.5003 到 1.0000）。
`γ → 1` 时这个比例趋近 0.5，因为这条链是「两步一个循环」，
每两步才拿一次 1，所以只用到界的一半。

**这个界必须记住**，两个用处：
① Day 32 证压缩映射时，`‖TV1 − TV2‖∞ ≤ γ‖V1 − V2‖∞` 的推导要用它；
② 调试时它是**诊断线** —— 你的 `V` 如果超过这个数，代码一定错了，不用查第二遍。

### 4.5 `γ = 1` 且任务不停 → 发散（实测）

| T（步数） | 部分和（`γ=1`，每步 +1） | `G_0`（`γ=0.9`） |
|---|---|---|
| 10 | 10.0 | 6.513216 |
| 100 | 100.0 | 9.999734 |
| 1000 | 1000.0 | **10.000000** |
| 10000 | 10000.0 | **10.000000** |

`γ=1` 时部分和等于 T，跟着步数一起长，**没有上界**。
`γ=0.9` 时 1000 步已经稳在 10.000000。

**这就是 `γ<1` 的第一个身份：它不是「偏好近处奖励」，它是收敛性的前提。**

补充一句，免得以后误用：**`γ=1` 不是绝对不能用**。
任务有终止态、且从任何状态出发都一定会终止时，总回报仍然是有限的
（比如下棋，最多 200 手就结束）。发散的前提是「无限期 + 有界奖励」。

## 五、回报是随机变量，值函数是它的期望

这是今天第二个容易糊的地方，而且它决定了后面所有算法长什么样。

### 5.1 `G_t` 是随机变量

给定 `s_0`，`G_0` 有几个可能取值？**取决于你怎么走、世界怎么变**。
从 4.1 的 `p(τ)` 可以看出，`G_t` 是轨迹的函数，而轨迹随机 → `G_t` 随机。

举个最直观的：同一个起点、同一个策略，跑两次，`G_0` 一般不同。
**所以「这个状态的回报是多少」这个问题本身没有唯一答案，除非你问期望。**

### 5.2 值函数 = 回报的期望

```
V^π(s) = E_π[ G_t | S_t = s ]          状态值
Q^π(s,a) = E_π[ G_t | S_t = s, A_t = a ]   动作值
```

三个必须记住的点：

1. **期望是对谁求的**：对 `π` 选动作 + 对 `P` 走世界，两重随机。
2. **`V^π` 带 `π` 上标**：它是「按策略 `π` 走」的值，换策略就换值。
   **`V` 不是环境的属性，是「环境 + 策略」的属性。**
3. **`V` 是一个确定的数**（给定 `π` 和环境），不是随机变量。
   `G_t` 随机，`E[G_t]` 不随机。**这个区分是后面一切估计方法的起点**：
   我们能采样的只有 `G_t`，想要的却是 `V`，所以永远在做「用样本估计期望」。

### 5.3 手算：两状态链

用第二节那条 `A ↔ B` 的链，`γ = 0.9`，奖励 `R(A)=1, R(B)=0`。
策略平凡（只有一个动作），所以 `V^π = V`。

**第一步，写出方程组**（这是 `V = E[G_t|S_t=s]` 展开后的样子，
Day 30 会证明它，今天先用）：

```
V(A) = 1 + γ V(B)
V(B) = 0 + γ V(A)
```

每一行的读法：站在 A，立刻拿 1，然后以概率 1 走到 B，之后从 B 起算的折扣值是 `γ V(B)`。

**第二步，消元**：

```
V(A) = 1 + γ·(γ V(A)) = 1 + γ² V(A)
V(A)·(1 − γ²) = 1
V(A) = 1/(1 − γ²)
```

`γ=0.9` → `1 − 0.81 = 0.19` → `V(A) = 1/0.19 = 5.263157894...`

**第三步，回代**：

```
V(B) = γ V(A) = 0.9 × 5.263157894 = 4.736842105...
```

**第四步，用完全独立的一条路验算**（实验 C）：

矩阵形式 `V = R + γPV` → `(I − γP)V = R` → `V = (I − γP)⁻¹R`

```
I − γP = [[1, −0.9],
          [−0.9, 1]]        det = 1 − 0.81 = 0.19
```

| | 手算 | 矩阵解 | 差 |
|---|---|---|---|
| `V(A)` | 5.26315789 | 5.26315789 | **0.000e+00** |
| `V(B)` | 4.73684211 | 4.73684211 | **0.000e+00** |

**严格相同，不是「接近」。**

这就是本周的核心工作方式：**同一个量用两条独立的路算，对上才算懂。**
一条是纸上的代数，一条是解线性方程组。前者验你的理解，后者验你的代码。
对不上时，**先怀疑自己的推导** —— W4 的经验是，`4 次断言失败里 3 次是我自己的问题`。

### 5.4 为什么「V 是期望」决定了后面所有算法

顺着 5.2 第 3 点往下推一步，整条主线就出来了：

```
已知 P 和 R  →  V 可以"算"出来      （DP：解方程，本周）
未知 P 和 R  →  V 只能"估"出来      （MC / TD：采样，W6）
P 和 R 都巨大 →  V 只能"近似"出来    （函数逼近 / DQN / PPO，W7+）
```

**这三种情形的差别不在算法花哨程度，在「你有什么信息」。**
今天把「已知 `P` 和 `R`」这条路走通，是因为它是唯一能拿到**精确答案**的，
有了精确答案，后面所有近似算法才有对拍的对象。

这也是为什么本周不写深度学习代码：**你需要的不是更多代码，是一个标准答案。**

## 六、`Q` 与 advantage（今天只需要认识）

```
V^π(s) = Σ_a π(a|s) Q^π(s,a)                     V 是 Q 在 π 下的加权平均
A^π(s,a) = Q^π(s,a) − V^π(s)                      advantage
```

`A` 的含义：**「在 s 做 a，比按 π 的平均水平好多少」**。
`A>0` 说明这个动作比平均好。PPO 的核心就是「提高 `A>0` 的动作的概率」——
到那时你会发现，整个 PPO 只是在估计这个量。

两个立刻能用的恒等式（今天先记着，Day 30 会推）：

```
Σ_a π(a|s) A^π(s,a) = 0        在 π 自己的分布下，advantage 的加权和为 0
V^*(s) = max_a Q^*(s,a)        最优时 V 和 Q 的关系（Day 31）
```

第一条值得停一下：它说明 **advantage 是一个「零均值」的量**，
所以它的正负才有意义，而它的大小是相对的。这个性质在 PPO 里被用来做归一化。

### 8.2 五条今天的结论（都来自实测）

1. **马尔可夫性是五元组里唯一的假设，且它是「你描述方式」的性质，不是世界的性质。**
   实测：把 A、B 压成同一观测，`E[G|观测]` 变成 5.263158 / 4.736842 两个值，
   **`V` 直接不存在**。而且这个差 `= 1/(1+γ)`，**下界 0.5** ——
   调 `γ` 缓解不了，是「有没有」的问题。
2. **`G_t = R_{t+1} + γG_{t+1}` 是恒等式，不是假设。**
   实测最大差 `0.000e+00`。它值得单独记，因为 Day 30–36 全由它展开。
