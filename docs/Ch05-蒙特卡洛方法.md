## 零、这一章的位置

第 6 课（随机近似）教了一个工具：**用采样平均代替期望**。但它举的例子都很干净 ——
`g(w)=0` 里的 `g` 是已知的，噪声只是加在上面。

这一章第一次真用它，而且**前提被抽掉了**：`P` 和 `R` 都不知道了。

```
第 3 章（贝尔曼）：V = R + γPV     需要 P 和 R → 只有 DP 能用
第 5 章（本章）：  V = E[G]        只需要样本   → 谁都能用
```

**MC 的全部内容就一句话：把「期望」换成「平均」。** 剩下的都是这句话的后果。

---

## 一、核心动作：一个符号的替换

Day 29 给过定义：

```
V^π(s) = E_π[ G_t | S_t = s ]
```

这个期望要算，得有 `P`。没有 `P`，只剩一条路：

```
V^π(s) ≈ (1/N) Σ_{i=1}^{N} G_t^{(i)}        ← N 条从 s 出发的 episode
```

**这就是蒙特卡洛。** 没有第二个思想。

### 1.1 两个直接后果

**后果 1：必须等 episode 结束。**
`G_t = R_{t+1} + γR_{t+2} + ...` 一直加到终止。
所以 MC 只能用于 **episodic** 任务 —— 有终止状态的那种。
连续任务（比如一直运行的机器人）它用不了。

**后果 2：每条 episode 只能给出「一个」`G`。**
这是 MC 样本效率低的根源。一条 20 步的 episode，对起点的 `V` 只贡献 **1 个**样本，
剩下的 19 步全白跑了（除非你把沿途状态也都统计上，那就是下面的「每次访问」）。

## 二、误差 ∝ 1/√N（实验 A）

### 2.1 实测

从固定起点跑 `N` 条 episode，估 `V^π(s0)`，8 个 seed 的 RMSE：

| `N` | 单状态 RMSE | 全表平均 | 全表 max |
|---|---|---|---|
| 100 | 0.026509 | 0.045426 | 0.161087 |
| 400 | 0.012027 | 0.025582 | 0.093038 |
| 1600 | 0.007062 | 0.012420 | 0.045325 |
| 6400 | 0.002714 | 0.007158 | 0.020816 |
| **log-log 斜率** | **−0.5316** | −0.4520 | −0.4947 |

第一列是**唯一干净的那条**：每条 episode 独立同分布，样本均值标准差 `= σ/√N`，
斜率就是 `−0.5`。实测 `−0.5316`，差 6%，在 8 个 seed 的噪声内。

### 2.2 三条推论

**推论 1：误差减半要 4 倍样本。**
这是 MC 的原罪。想从 0.01 精度做到 0.005，episode 数要翻四倍。
对比 DP：9 轮精确收敛，一步不多。

**推论 2：「误差 ∝ 1/√N」只对 iid 那条成立。**
后两列都偏平。原因有两个：

- **访问不均**：从固定起点出发，远端状态被经过的次数远少于近端，它是瓶颈（对应第二列）；
- **同 episode 内相关**：一条 episode 里同一个状态可能被访问多次，那些 `G` 不独立（见实验 B 的冗余率 2.81）。

所以讲「MC 的误差 ∝ 1/√N」时，说的是**单个状态**、**每条 episode 只采样一次**的那种。
估整张表会更慢，慢多少取决于状态被访问得多均匀。

**推论 3：`max` 误差不能当判据。**
第三列由**最差的那个状态**决定，单次波动极大（同一份代码两次跑出过 `−0.5617` 和 `−0.4947`）。
这是老问题的又一个版本：**指标的统计性质不同，收敛速率就不同**，
不能拿一个数直接和理论比。

### 2.3 这一节我改了三次才对

第一次用 `max` 误差、3 个 seed，测出斜率 `−0.3936`，以为是理论错了。
改成「按访问次数拟合」还是 `−0.4397`。
换成「单状态 + 8 个 seed + RMSE」才得到 `−0.5316`。

> 教训：**测不出理论值时，先怀疑自己的估计量，别怀疑理论。**
> `mean(|err|)` 的单个样本相对波动有 50%，3 个 seed 平均根本不够。

## 三、首次访问 vs 每次访问（实验 B）

一条 episode 可能多次经过同一个状态，于是有两种统计方式：

| 方式 | 做法 |
|---|---|
| **首次访问**（first-visit） | 每条 episode 里，每个状态只取**第一次**的 `G` |
| **每次访问**（every-visit） | 每次经过都算一个样本 |

### 3.1 实测（80 次重复 × 200 episode）

| | 平均 std | 平均 \|偏差\| |
|---|---|---|
| 首次访问 | 0.043870 | 0.006185 |
| 每次访问 | 0.043336 | 0.003875 |
| **同比** | **0.9878** | 0.6265 |

**访问冗余率 = 2.8102**（总访问次数 / 首次访问次数）。

### 3.2 这张表说了什么

**每次访问多了 181% 的样本，方差却只低了 1.2%（还在噪声里），偏差低 37%。**

两个结论：

1. **多出来的样本几乎全是冗余。** 同一条 episode 里，后面的 `G` 由前面的 `G` 决定
   （它们共享大部分未来），不是新信息。
2. **教科书说「首次访问方差略小」，这里没能复现。** 80 次重复下两者差 1.2%，
   而这个样本量下方差估计本身的标准误就有 8%。
   **诚实记为「测不出」，不写成「首次访问更好」。**

> 实践中两者的差别通常不重要，**选哪个取决于实现方便**。
> 这里真正值得带走的是「冗余率 2.81」这个数 —— 它解释了为什么 MC 的样本效率这么低。

## 四、MC Basic：为什么必须估 `q`，不能估 `v`

### 4.1 这一步不能跳

策略改进要做的是：

```
π'(s) = argmax_a q^π(s, a)
```

如果你手里只有 `v^π(s)`，**选不出动作** —— 因为 `v` 是 `|A|` 个 `q` 的一个聚合（最大值）。

有模型时可以还原：

```
q(s,a) = R(s,a) + γ Σ_{s'} P(s'|s,a) V(s')
```

**没有模型时，这条路断了。** 从 `v` 推不出 `q`，信息不够。

> 这是「model-free」的第一个结构性后果，也是后面所有算法的分界线：
> **DP 估 `v` 就够了（它有模型），MC / TD / Q-Learning 必须估 `q`。**

### 4.2 算法

```
π_0 = 任意策略
重复:
  评估：对每个 (s,a)，跑 N 条从 (s,a) 出发的 episode，估 q^π(s,a)
  改进：π(s) ← argmax_a q^π(s,a)
直到 π 不再变化
```

`P` 和 `R` 一次都没用到 —— 这就是它叫 model-free 的意思。

## 五、理论保证 vs 实测回退（实验 C）

### 5.1 理论怎么说

第 4 章那块砖（策略改进定理）说的是：

> 若 `q^π` **精确**，且 `π'(s) = argmax_a q^π(s,a)`，则 `V^{π'} ≥ V^π`（逐状态）。

证明只有三行（用 `q^π(s,π'(s)) ≥ q^π(s,π(s)) = V^π(s)` 起手），
**但它的前提是「`q^π` 精确」。**

### 5.2 实测：`q` 是估的，所以会回退

5 轮 MC Basic，记录每轮策略的**精确** `V^π(s0)`（用解析解算，不用估计值 —— 否则是循环论证）：

| `N`（每个 (s,a) 的 episode 数） | 回退次数 | **最大回退幅度** | 末轮距最优 |
|---|---|---|---|
| 5 | 3 | **0.013748** | 0.001060 |
| 20 | 1 | **0.000841** | 0.000027 |
| 50 | 1 | **0.000134** | 0.000834 |

`V*(s0) = 0.556962`，初始均匀策略 `V = −0.3955`。

三条读法：

1. **`N=5` 时真的变差了**：`−0.3955 → −0.4092`，掉 0.0137。
   理论保证在这里失效，因为 `q` 的估计误差比动作之间的真实差距还大。
2. **回退幅度随 `N` 掉得比 `1/√N` 快得多**：
   `N` 涨 4 倍（5→20），幅度降 **16.3 倍**；`N` 涨 2.5 倍（20→50），降 **6.3 倍**。
   两个区间都接近平方关系。
3. **末轮距最优不单调**（`N=20` 最好，`N=50` 反而差）。
   因为最优策略不唯一，采样噪声让策略在**并列的最优动作**之间来回跳，
   `V` 只动 `1e-4` 量级。**这不是改进失败，是同一个最优值的不同写法。**

> 第 3 条是个容易误判的点：数「回退几次」会得到 `N=50` 和 `N=20` 一样的答案，
> 必须看**幅度**才能分开「真变差」和「并列间跳」。

## 六、探索：怎么保证每个 `(s,a)` 都被采到

### 6.1 问题

MC Basic 的改进是**确定性**的（`argmax`）。
一旦 `π` 变成确定性策略，只有被选中的那个动作会被执行 →
其他 `(s,a)` 永远拿不到样本 → `q` 停在初始值 → `argmax` 是瞎选的。

### 6.2 p19 的解法：exploring starts

每条 episode **从随机的 `(s,a)` 开始**，保证每个 `(s,a)` 都有机会被采样。

上面实验 C 用的就是它。**但这个假设在实际中做不到** ——
你没法把机器人瞬移到任意状态再让它从某个动作开始。

### 6.3 p20 的解法：ε-greedy

不再强制起点，而是让策略本身**永远保留一点随机性**：

```
π(a|s) = { 1 − ε + ε/|A|   若 a = argmax q(s,·)
         { ε/|A|           否则
```

这样每个动作都有至少 `ε/|A|` 的概率被执行，样本自然会覆盖到。
**代价是最终策略不再是贪心的。**

### 6.4 这个代价有多大（实验 E）

| `ε` | `V*(s0) − V_ε(s0)` | `ε/(1−ε)` | 比值 |
|---|---|---|---|
| 0.01 | 0.005752 | 0.0101 | **0.5694** |
| 0.05 | 0.025706 | 0.0526 | **0.4884** |
| 0.10 | 0.052188 | 0.1111 | **0.4697** |
| 0.20 | 0.113604 | 0.2500 | **0.4544** |
| 0.50 | 0.367070 | 1.0000 | **0.3671** |

最后一列在 `0.37–0.57` 之间，**近似常数**。所以

```
V* − V_ε  ≈  0.5 · ε/(1−ε)
```

**代价与 `ε/(1−ε)` 成正比，比例常数由环境定（这里是 0.5）。**

注意这个函数的形状：`ε` 从 0.01 到 0.10 只涨 10 倍，`ε/(1−ε)` 涨 11 倍；
但 `ε` 从 0.10 到 0.50，`ε/(1−ε)` 涨 **9 倍**（0.111 → 1.0）。
所以 **`ε` 大的时候，每加一点 `ε` 都在加速变差**，不是线性的。

> 这条曲线是后面所有「探索调度」的老祖宗：
> `ε` 必须随训练衰减，而且要衰减到很小才能逼近最优。

## 七、model-free 的账单（实验 D）

同一个 5×5 GridWorld，两条路各要花多少：

| | DP（第 4 章） | MC（本章） |
|---|---|---|
| 可达 `(s,a)` 对数 | — | **92** |
| 平均 episode 长度 | — | **23.576** 步 |
| 每轮计算量 | 2500 次乘加（`nS²·nA`） | 9200 条 episode |
| 9 轮 / 一轮的总量 | 22500 次乘加 | **216900 步环境交互** |
| **环境交互** | **0 步** | **216900 步** |

**DP 一步都不用走**，因为它有 `P`。
**MC 走一轮评估就要 21.7 万步**，因为它只能靠走。

这就是为什么「有模型」和「没模型」要分开讲 —— 不是算法优劣，是**信息量的差别**。

## 八、这一章没给你什么

| 缺口 | 后果 | 在哪补 |
|---|---|---|
| **必须等 episode 结束** | 连续任务、长 episode 用不了 | **第 7 章 TD**，这是它的全部动机 |
| 没讲 off-policy MC / 重要性采样 | 不能复用旧数据 | 第 7 章会碰到概念 |
| 没讲「episode 内增量更新」 | 内存要存整条轨迹 | 第 6 章的迭代均值可直接套 |
| 没讲高维状态怎么办 | `q` 表有 `|S|×|A|` 项，状态一多就爆 | **第 8 章 值函数近似** |
| MC Basic 的样本效率没优化 | 每个 `(s,a)` 单独跑 `N` 条，浪费 | 第 7 章之后再说 |

**最关键的缺口是第一条。** MC 的整个设计都建立在「能等到终止」上。
而真实任务里，要么 episode 很长（一盘棋几千步），要么根本没有终止（一直运行的机器人）。
第 7 章的 TD 就是把这个前提也抽掉：**不等结束，走一步就更新一次。**
