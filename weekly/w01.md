## 三、卡住的地方

### 1. `conda activate pytorch` 在 PowerShell 里无效

**现象**：执行后报「系统找不到指定的路径」，环境没切过去。

**根因**：本机 conda 4.10.3 **从未对 PowerShell 做过初始化**，
`conda activate` 依赖的 hook 脚本不存在。这是安装方式的问题，不是命令写错。

**解法**：放弃 activate，一律用完整路径直调：

```powershell
& "E:\anaconda\envs\pytorch\python.exe" scripts\env_info.py
```

**连带发现**：PATH 里的 `python` 指向另一个独立安装的 Python 3.12
（`C:\Users\...\Programs\Python\Python312`），**里面没装 torch**。
所以「直接敲 `python`」会 `ModuleNotFoundError`，而且报错信息完全不提
"你在错误的解释器里"。

### 2. 路径含空格

`E:\work Buddy\强化学习\...` 里有空格，PowerShell 里**必须加引号**，
而且**命令开头必须有 `&`**（路径被引号包成字符串后不加 `&`，
PowerShell 会把它当字符串输出而不是执行）。

### 3. 装包装错地方

用裸 `pip install` 会装进那个野生 Python 3.12，在 conda 环境里永远 import 不到。
必须 `& "E:\anaconda\envs\pytorch\python.exe" -m pip install ...`。
