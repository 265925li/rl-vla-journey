## 三、卡住的地方

> 按「报错原文 + 根因」记，不写「环境有问题」这种没法复盘的话。

### 1. `for _ in (n_layers-1)` → `TypeError: 'int' object is not iterable`

想循环 N 次，直接拿整数去迭代。同一天在 `for _ in range(model.modules())` 又犯一次反向的
（`TypeError: 'generator' object cannot be interpreted as an integer`）。
**一天之内同一个知识点正反两面各踩一次。**

### 2. `layers.append(act_cls)` → `TypeError: ReLU is not a Module subclass`

这个报错文案是**骗人的**——`ReLU` 确实是 `Module` 的子类，错在传的是**类**不是**实例**。
正确写法 `act_cls()`。教训：报错文案不可全信，要看它说的和你想的是不是一回事。

### 3. `dW1 = X.T @ dlogits` → `AssertionError: dW1 形状应为 (5,4)，实际 (5,3)`

**只替换了一半变量**。反传是逐站传递的：`W1` 直接连 `z1`，必须用上游传下来的 `dz1`，
不能用更远的 `dlogits`。这类错误不报错时最危险（`H == C` 时形状也能对上）。

### 4. `p.data -= lr * g` 写进了 `else` 分支 → 开 momentum 时参数永不更新

缩进多了一层。**关 2 的五个配置全部对不上**，但程序不报错，表现是「训练毫无进展」。
这是本周最典型的一个：语法完全合法，逻辑完全错误，没有任何提示。

### 5. 手动删除 `raise AssertionError` 占位符（含未实现的 TODO）

删掉报警器后，未完成的 TODO 3 用脏数字（648）继续跑，输出看着"正常"。
**规矩定下来：先写实现，跑通，再删占位符。**

### 6. `np.einsum("bld,bsd -> bls", B, L, S)` → `ValueError: too many subscripts for operand 0`

把形状变量当数组传进去了。上个月同类错误是「字母数 ≠ 数组维数」。
**einsum 的字母数必须等于对应数组的维数**，两次都是这个。

### 7. 自己写对拍代码时踩的坑：`max([0.0, nan, ...])` 返回 `0.0`

`Adam` 里漏 `self.t += 1` → 除零 → 参数变 `nan`，但检查判了 PASS。
因为 `nan > 0.0` 是 `False`，`max` 把 nan 跳过了，而 `diffs[0]` 恒为 0（起点相同）。
**检查代码本身也会骗人**，补了 `torch.isfinite()` 才抓住。

### 8. `.gitignore` 里写 `data/` 吞掉 `src/data/` 源码

无前导斜杠的目录规则匹配**任意层级**，`git add` 静默无效。
改成 `/data/`、`/datasets/`。判断命令：`git check-ignore -v <路径>`。
