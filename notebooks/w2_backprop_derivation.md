## 二、第 1 步：`∂L/∂z2`（核心，慢慢来）

### 2.1 先求 `∂p_i/∂z_k`

**关键观察**：`z_k` 出现在两个地方——它可能在分子（当 `k == i` 时），但**永远在分母里**（分母是全部类的指数和）。

分成两种情况推。

**情形 A：`i == k`**（被求导的 logit，正好对应正在看的那个概率）

用商的求导法则 `(u/v)' = (u'v - uv')/v²`，其中 `u = e^{z_k}`、`v = Σ_j e^{z_j}`：

```
∂p_k/∂z_k = _________________________________________
```

化简到只剩 `p_k` 的形式：

```
∂p_k/∂z_k = ______________
```

**情形 B：`i != k`**（分子与 `z_k` 无关，所以 `u' = 0`）

```
∂p_i/∂z_k = _________________________________________
```

化简：

```
∂p_i/∂z_k = ______________
```

**两种情形合写成一个式子**（用 `δ_ik`：`i==k` 为 1，否则 0）：

```
∂p_i/∂z_k = ______________________________
```

> 如果合并不出来，把 A 和 B 的结果分别代 `δ=1` 和 `δ=0` 检查一遍，看能不能统一。

### 2.2 代回 `∂L/∂z_k`

`L = -log p_y`，所以先求 `∂L/∂p_y`：

```

```


把 2.1 的结论代进去，`p_y` 会约掉。

## 附：这次推出来的结论，后面在哪用

| 结论 | 下次遇到它的地方 |
|---|---|
| `dlogits = p - onehot` | **所有**分类任务的策略梯度起点；Day 20 之后 PPO 的 ratio 也是从"策略的动作概率"推 |
| `dW = 激活值ᵀ @ 上游梯度` | 手写线性层（Day 17）、QLoRA 的 LoRA 层梯度 |
| `da = 上游梯度 @ Wᵀ` | 上面那条的反向，`Wᵀ` 出现在这里是因为"线性映射反传要用转置" |
| `dz = da * (z>0)` | 所有逐元素非线性层；GRU/LSTM 的门控也是同一套 |
| `db = 上游.sum(axis=0)` | 所有带广播的偏置 |
| 有限差分做裁判 | P2 之后调试任何自定义 loss 时，这是唯一的独立验证手段 |
